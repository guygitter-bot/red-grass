# תקציב הבית

אפליקציה (טלפון ומחשב, מותקנת מהדפדפן: "הוספה למסך הבית") לניהול ההוצאות וההכנסות של הבית לפי חודשים –
במקום קובץ האקסל. רואים לכל חודש, גם רחוק קדימה, כמה ייכנס וכמה ייצא לפי ההכנסות הקבועות, ההוצאות הקבועות והתשלומים.

כתובת: **https://bayit-budget.pages.dev** · שרת: Worker `bayit-budget-api` (סוד `ANTHROPIC_API_KEY` ליועץ ה-AI) · עלייה: `.github/workflows/bayit-budget.yml` אחרי מיזוג ל-main.

## מה יש

- **חודש** – הכנסות צפויות, הוצאות צפויות, כמה נשאר, ויתרה צפויה בבנק בסוף החודש. השורות מחולקות להכנסות, הוצאות קבועות,
  תשלומים (עם "תשלום 3/12") וחד־פעמיות. חצים לחודש הקודם/הבא, ו"לפי קטגוריה".
- **לחיצה על שורה** – סכום אחר רק לחודש הזה (למשל חשבון חשמל גבוה בחורף), "לא בחודש הזה", או עריכה בכל החודשים.
- **סוגים**: קבועה (כל חודש / חודשיים / רבעון / חצי שנה / שנה, עם חודש סיום או בלי), תשלומים (סכום לתשלום + מספר תשלומים),
  חד־פעמית (חודש אחד). כרטיסי אשראי והוצאות משתנות – אפשר להוסיף כחד־פעמית בחודש, אם רוצים.
- **דוח חודשי** (`#/report/<חודש>`) – כמו הגיליון החודשי באקסל: כרטיס לכל קטגוריה (שם, סכום, פירוט "קבוע" / "3/10",
  אמצעי תשלום), סה"כ לכל קטגוריה, וסיכום הכנסות / הוצאות / יתרה. הדפסה והורדה לאקסל (CSV).
- **גרפים** (`ChartsView.jsx`, SVG בלי ספרייה) – הכנסות מול הוצאות (חצי שנה אחורה וקדימה), לאן הולך הכסף (עוגה לפי קטגוריה),
  יתרה צפויה, כרטיסי אשראי בפועל, ההוצאות הגדולות ותשלומים שמסתיימים בקרוב.
- **תובנות AI** (`InsightsView.jsx`) – שאלות מוכנות (תמונת מצב, איפה לחסוך, ביטוחים, הלוואות, החודשים הקרובים, כרטיסים,
  יעד חיסכון, מנויים) או שאלה חופשית. האפליקציה בונה סיכום טקסט של התקציב (`aiContext` ב-`budget.js`) ושולחת לשרת (`/ai`,
  `api/ai.js`, Claude, עד 40 שאלות ביום). התשובות נשמרות כרשומות `insight` ומסתנכרנות.
- **כרטיסי אשראי** (`CardsView.jsx`) – כמה ירד מכל כרטיס בכל חודש (כמו "מעקב כרטיסים" באקסל). מעקב בלבד, לא נכנס לסיכום.
- **ייבוא מאקסל** (הגדרות) – הקובץ נקרא במכשיר (`lib/xlsx.js` – קורא xlsx בלי ספרייה, `lib/excelImport.js`): גיליון לכל חודש
  ("08.26"), בלוקים לפי כותרת "סכום" (שם משמאל, "פירוט" מימין, ואחריו אמצעי תשלום), שורה בלי סכום אחרי סה"כ = קטגוריה,
  "הכנסות" = הכנסות. "קבוע" / מופיע בכמה חודשים → קבועה; "3/10" → תשלומים; השאר חד־פעמי. בכל חודש שבו הסכום באקסל
  היה אחר – נשמר סכום לאותו חודש, כך שכל חודש יוצא כמו באקסל. מזהים קבועים לפי השם – ייבוא חוזר לא מכפיל.
  קובץ לדוגמה (נתונים מומצאים): `web/src/lib/fixtures/sample.xlsx`. **לא להכניס למאגר את הקובץ האמיתי של המשתמש.**
- **איפוס** (הגדרות ← אזור מסוכן) – מסך אזהרה, גיבוי לפני, הקלדת "מחק הכול" וסיסמה. השרת (`/reset`) הופך כל רשומה
  ל"נמחקה", כך שהמחיקה עוברת לכל המכשירים.
- **שנה קדימה** – 12 חודשים בטבלה (במחשב) או ברשימה (בטלפון), עם פסים של הכנסות מול הוצאות ויתרה מצטברת. לחיצה פותחת את החודש.
- **הכול** – כל הרשומות, חיפוש, פעילות / שהסתיימו.
- **הגדרות** – יתרה בבנק בתחילת חודש (ממנה מחושבת היתרה הצפויה), מצב לילה, ייצוא לאקסל (CSV, 24 חודשים),
  גיבוי ושחזור לקובץ, החלפת סיסמה, יציאה מהמכשיר.

## איפה הנתונים

- כל מכשיר שומר עותק (localStorage) – האפליקציה עובדת גם בלי אינטרנט.
- בשרת (`api/budget.js`, Durable Object אחד): כל רשומה עם `updatedAt`; העריכה המאוחרת גוברת; מחיקה = `deleted: true`.
  כל שינוי מקבל `rev`, והמכשיר מבקש "מה השתנה מאז" (`/sync`). סנכרון: בפתיחה, כשחוזרים לאפליקציה, כשהרשת חוזרת,
  פעם בדקה ושנייה וחצי אחרי שינוי (`web/src/lib/store.js`). סמל הענן בכותרת מראה את המצב.
- **סיסמה אחת**, שנקבעת בכניסה הראשונה בכלל (`/setup`). כל מכשיר נכנס פעם אחת ונשאר מחובר (שנה, מתחדש בשימוש).
  10 טעויות ברצף – נעילה לרבע שעה. החלפת סיסמה מנתקת את שאר המכשירים.

## מבנה הרשומות (`web/src/lib/budget.js`)

- `item`: `kind` (income/expense), `type` (fixed/installments/once), `name`, `category`, `amount`, `start` ('YYYY-MM'),
  `end` (קבועה), `every` (קבועה), `count` (תשלומים), `note`.
- `override`: `itemId`, `month`, `amount` – סכום אחר בחודש אחד (0 = לא בחודש הזה). המזהה: `ov:<itemId>:<month>`.
- `settings` (מזהה `settings`): `balance`, `balanceMonth`.
- `card`: `name`, `month`, `amount` (מזהה `card:<name>:<month>`). `insight`: `question`, `answer`, `month`, `at`.
- ב-`item` גם `payment` (אמצעי תשלום).
- שדה חדש – חייב ברירת מחדל ב-`safeItem` (רשומות ישנות מסתנכרנות בלי אותו שדה).

## בדיקה

- `cd budget/api && npm test` · `cd budget/web && npm test && npm run build`
- בדפדפן: לבנות עם `VITE_API_URL=http://localhost:8787` ולהריץ את ה-Worker מקומית (או שרת node קטן שעוטף את `worker.js` עם אחסון מדומה).
