# ערוץ מוזיקה מסונו – קורס אינטראקטיבי

קורס בעברית (18 פרקים) על בניית ערוץ יוטיוב של פלייליסטים ממוזיקה שנוצרת ב-Suno: בחירת נישה, פתיחת ערוץ,
עבודה בסונו, ויזואל ועריכה ב-CapCut, העלאה וקידום, זכויות יוצרים, מדיניות יוטיוב, מונטיזציה ומיסים, ושכפול לערוצים.

- מפורסם כ-Artifact ב-claude.ai: https://claude.ai/artifact/R71RyEcJx5dCCvZm7KXn3h
- יכולות: `sample` (מדריך AI, מעבדת נישות, שיפור פרומפטים), `db` + `user` (מעקב ערוץ פרטי לכל צופה, `data/users/<id>/tracker`).
- כלים: מחשבון הכנסות (כולל סף 8,000 שעות מ-2.2027), מחשבון הורדות סונו, מחולל פרומפטים, ספריית פרומפטים,
  מחולל כותרת/תיאור/פרקי זמן, חידון זכויות, בדיקה עצמית, מעקב עם ייבוא CSV מיוטיוב סטודיו.
- איורי המסכים הם שחזור ב-HTML (לא צילומים) – `src/04-mocks.js`.

## עדכון
1. עורכים את הקבצים ב-`src/` (תוכן: `05-content-*.js`, כלים: `07-tools.js`).
2. `./build.sh` → `course.html`.
3. מפרסמים מחדש לאותה כתובת (Artifact עם `url`).

הנתונים בקורס נאספו באוקטובר 2026 ממקורות משניים; מחירים, ספים ומכסות מסומנים לבדיקה בדפים הרשמיים.
