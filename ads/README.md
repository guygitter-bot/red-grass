# סרטוני פרסומת

סרטון = עמוד HTML באנימציה (`<שם>/ad.html`, 1080×1920 לאורך) שמצולם פריים אחרי פריים ומחובר למוזיקה.

```
node ads/render.mjs "$PWD/ads/falafel_bariboa" out.mp4 mat_kon/tutorials/music.m4a
# בדיקה מהירה – רק תמונות ברגעים מסוימים:
node ads/render.mjs "$PWD/ads/falafel_bariboa" check x 2.5,11.8,23.5
```

- `falafel_bariboa/` – פלאפל בריבוע קרית השרון: צ'יפס חינם בכל מנת פלאפל, א׳–ה׳ 12:00–15:00 (30 שניות).
