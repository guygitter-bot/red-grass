# מורה לגיטרה

אפליקציה בעברית (מימין לשמאל) ללימוד גיטרה לבד: מורה בתלת־ממד שיושב ומנגן, תקריבים על האצבעות, כוונון עם המיקרופון ושיעורים צעד אחר צעד.
רעיונות ותכנון: `IDEAS.md`. סקיצה ראשונה: `sketch/lesson1.html`.

- **האפליקציה:** `web/` (React + Vite + Tailwind + three.js) → https://music-teacher.pages.dev. אין שרת.
- **גיטרה:** קלאסית או חשמלית (נשמר במכשיר). הדגם, שמות החלקים והצליל משתנים.

## מבנה (`web/src`)
- `three/guitar.js` – דגם הגיטרה (שתי גרסאות), חלקים להדגשה, מיתרים רוטטים.
- `three/teacher.js` – המורה (בובת חימר, ידיים עם אצבעות ו-IK). ממשק נקי להחלפה בדמות קנויה בעתיד (תיאור בראש הקובץ).
- `three/stage.js` – סצנה, מצלמות (מעברים של שנייה), תוויות, גרירה ולחיצה על מיתר.
- `lib/pitch.js` – זיהוי גובה צליל (YIN) וכלי תווים; `lib/audio.js` – צליל Karplus-Strong; `lib/mic.js` – מיקרופון.
- `lib/lessons.js`, `lib/parts.js`, `lib/notes.js` – תוכן השיעורים, חלקים ומצלמות, מיתרים.
- `screens/` – בית, שיעור 1 (הכירו את הגיטרה), שיעור 2 (Am), מכוון.

## הרצה ובדיקה
`cd music_teacher/web && npm install && npm run dev` · בדיקות: `npm test` · בנייה: `npm run build`.
כללים: טלפון + מחשב + מצב לילה (`bg-card` / `bg-page`), `useEffect` עם סוגריים, הערות בעברית.
שינוי בדגם או במצלמה: לבדוק בדפדפן (Playwright עם `--use-gl=swiftshader`).

## עלייה לאוויר
`.github/workflows/music-teacher.yml` – בדיקות ובנייה בכל PR; אחרי מיזוג ל-main עולה ל-Cloudflare Pages (פרויקט `music-teacher`, נוצר אוטומטית בריצה הראשונה).
המיקרופון עובד רק בכתובת מאובטחת (https) ואחרי אישור המשתמש; הכותרות ב-`web/public/_headers`.
