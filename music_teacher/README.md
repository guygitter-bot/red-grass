# מורה לגיטרה

אפליקציה בעברית (מימין לשמאל) ללימוד גיטרה לבד: מורה בתלת־ממד שיושב ומנגן, תקריבים על האצבעות, כוונון עם המיקרופון ושיעורים צעד אחר צעד.
רעיונות ותכנון: `IDEAS.md`. סקיצה ראשונה: `sketch/lesson1.html`.

- **האפליקציה:** `web/` (React + Vite + Tailwind + three.js) → https://music-teacher.pages.dev. אין שרת.
- **גיטרה:** קלאסית או חשמלית (נשמר במכשיר). הדגם, שמות החלקים והצליל משתנים.

## מבנה (`web/src`)
- `three/guitar.js` – דגם הגיטרה (שתי גרסאות), חלקים להדגשה, מיתרים רוטטים.
- `three/teacher.js` – המורה הבובה (חימר, ידיים עם אצבעות ו-IK): גיבוי כשהדמות עוד נטענת או נכשלה. הממשק מתואר בראש הקובץ.
- `three/teacherModel.js` – **המורה האמיתי**: דגם GLB עם שלד, אותו ממשק בדיוק. תנוחת ישיבה, IK לזרועות, ו-CCD לאצבעות (כל קצה אצבע נוחת מאחורי השריג הנכון – בדיקה: Am בטווח ~0.3 מ"מ).
- `lib/teachers.js` – רשימת המורים (מקום אחד). `lib/storage.js` – הבחירה נשמרת במפתח `mt_teacher` (ברירת מחדל `male`, ערך לא מוכר = גבר).
- `three/stage.js` – סצנה, מצלמות (מעברים של שנייה), תוויות, גרירה ולחיצה על מיתר.
- `lib/pitch.js` – זיהוי גובה צליל (YIN) וכלי תווים; `lib/audio.js` – צליל Karplus-Strong; `lib/mic.js` – מיקרופון.
- `lib/lessons.js`, `lib/parts.js`, `lib/notes.js` – תוכן השיעורים, חלקים ומצלמות, מיתרים.
- `screens/` – בית, שיעור 1 (הכירו את הגיטרה), שיעור 2 (Am), מכוון.

## המורה (דמות תלת־ממד)
- הקובץ: `web/public/teachers/male.glb` (~1.4 MB, טקסטורה WebP 1024). נטען בעצלות כשנפתחת במה; עד אז (או אם נכשל) רואים את הבובה.
- איך נוצר: Tripo (תמונה → דגם) → Retopo ל-10 אלף מרובעים → Mixamo (Standard Skeleton 65, T-pose) → FBX → המרה ל-GLB (FBXLoader + GLTFExporter, `gltf-transform weld` ו-`webp`). שמות העצמות `mixamorig…` (אצבעות כולל), קוד המורה מסתמך עליהם.
- **שני מורים:** `male.glb` ו-`female.glb` (~2 MB). לכל דמות `fit` ב-`lib/teachers.js` (קנה מידה והזזת הגיטרה – לאישה זרועות קצרות יותר, אז הגיטרה קרובה יותר).
- **להוסיף מורה חדש:** לייצר GLB באותו תהליך, לשים ב-`public/teachers/`, להוסיף שורה ב-`TEACHERS` (אפשר `comingSoon: true` עד שמוכן) ולכוון `fit` לפי צילום מסך וביקורת קצות האצבעות.
- ה-CSP (`public/_headers`) כולל `blob:` ב-`connect-src` – בלי זה כרום לא טוען את הטקסטורה שבתוך ה-GLB.
- בחירת המורה: בדף הבית (כרטיסים) ובכותרת בשיעורים (כפתור האדם).

## הרצה ובדיקה
`cd music_teacher/web && npm install && npm run dev` · בדיקות: `npm test` · בנייה: `npm run build`.
כללים: טלפון + מחשב + מצב לילה (`bg-card` / `bg-page`), `useEffect` עם סוגריים, הערות בעברית.
שינוי בדגם או במצלמה: לבדוק בדפדפן (Playwright עם `--use-gl=swiftshader`).

## עלייה לאוויר
`.github/workflows/music-teacher.yml` – בדיקות ובנייה בכל PR; אחרי מיזוג ל-main עולה ל-Cloudflare Pages (פרויקט `music-teacher`, נוצר אוטומטית בריצה הראשונה).
המיקרופון עובד רק בכתובת מאובטחת (https) ואחרי אישור המשתמש; הכותרות ב-`web/public/_headers`.
