# מורה לגיטרה

אפליקציה בעברית (מימין לשמאל) ללימוד גיטרה לבד: מורה בתלת־ממד שיושב ומנגן, תקריבים על האצבעות, כוונון עם המיקרופון ושיעורים צעד אחר צעד.
רעיונות ותכנון: `IDEAS.md`. סקיצה ראשונה: `sketch/lesson1.html`.

- **האפליקציה:** `web/` (React + Vite + Tailwind + three.js) → https://music-teacher.pages.dev. אין שרת.
- **גיטרה:** קלאסית או חשמלית (נשמר במכשיר). הדגם, שמות החלקים והצליל משתנים.

## מבנה (`web/src`)
- `three/guitar.js` – דגם הגיטרה המחושב (שתי גרסאות): מיתרים רוטטים, שריגים, חלקים להדגשה. כשהגיטרה האמיתית נטענת (`attachModel`) הגוף/הראש/הצוואר המחושבים מוסתרים והחלקים להדגשה הופכים לתיבות זוהרות שקופות על הדגם.
- `three/guitarModels.js` – גיטרות אמיתיות (`public/guitars/classical.glb`, `electric.glb`, מ-Tripo): טעינה עצלה, כיול (נקודות האום והאוכף במערכת הדגם -> מיקום/סקאלה/הטיה, `modelFrame`), מחיקת מיתרים אפויים וצוואר חתוך, ומיקומי חלקים. עד שהדגם נטען (או אם נכשל) רואים את הגיטרה המחושבת. מיתרים ושריגים תמיד מחושבים אצלנו.
- `three/labels.js` – פריסת תוויות בלי חפיפה ובתוך הבמה.
- `three/teacher.js` – המורה הבובה (חימר, ידיים עם אצבעות ו-IK): גיבוי כשהדמות עוד נטענת או נכשלה. הממשק מתואר בראש הקובץ.
- `three/teacherModel.js` – **המורה האמיתי**: דגם GLB עם שלד, אותו ממשק בדיוק. תנוחת ישיבה, IK לזרועות, ואצבעות שמאל מקושתות (`archFinger`: הקצה יורד בניצב ללוח, המפרקים למעלה) עם כיול נקודת המגע על העור (`calibrate`, `contactPoints`) – בדיקה: `teacher._debug.clearance()` מחזיר לכל אצבע את הסטייה מ(מיתר, שריג) היעד ולכל עצם את המרווח ממיתרים 1 ו-5 (יעד: סטייה עד ~0.1 יחידה, מרווח חיובי). חתך עצמות האצבעות מוקטן (`setSlim`) כדי שהמיתרים יראו בין האצבעות; `fit.knuckleH/knuckleBack` מכוונים את הקשת לכל דמות.
- `lib/teachers.js` – רשימת המורים (מקום אחד). `lib/storage.js` – הבחירה נשמרת במפתח `mt_teacher` (ברירת מחדל `male`, ערך לא מוכר = גבר).
- `three/stage.js` – סצנה, מצלמות (מעברים של שנייה), תוויות, גרירה ולחיצה על מיתר.
- `lib/pitch.js` – זיהוי גובה צליל (YIN) וכלי תווים; `lib/audio.js` – צליל Karplus-Strong; `lib/mic.js` – מיקרופון.
- `lib/lessons.js`, `lib/parts.js`, `lib/notes.js` – תוכן השיעורים, חלקים ומצלמות, מיתרים. `CHORDS` ב-`lessons.js` = כל האקורדים (מפרט `{name, fingers:[{finger,string,fret}], open, muted}`); אקורד חדש = רשומה חדשה, בלי קוד.
- `lib/chord.js` – מפרט אקורד: בדיקת תקינות (`validateChord`), צבע לכל אצבע, מיקום הסימונים על הצוואר (`chordMarkers`) וסדר האנימציה (`fingersDownAt`). בדיקות ב-`chord.test.js`.
- `three/chordAids.js` – עזרי הוראה בתקריב האקורד: עיגולים ממוספרים וצבעוניים על המיתר (מעל היד, x-ray), O/X ליד האום, הדגשת המיתרים הלחוצים וטבעת בצבע האצבע על הקצה. אותם צבעים ומספרים כמו בדיאגרמה בפאנל. מצלמת התקריב: `PRESETS.*.chord` (מבט מלמעלה על פני הלוח, `phi` = הטיה מהניצב). כפתורים בשלב: "הצג שוב" ו"יד שקופה" (`stage.replayChord`, `stage.setGhost`). עם "הפחתת תנועה" הכול מונח מיד.
- `screens/` – בית, שיעור 1 (הכירו את הגיטרה), שיעור 2 (Am), מכוון.

## המורה (דמות תלת־ממד)
- הקובץ: `web/public/teachers/male.glb` (~1.4 MB, טקסטורה WebP 1024). נטען בעצלות כשנפתחת במה; עד אז (או אם נכשל) רואים את הבובה.
- איך נוצר: Tripo (תמונה → דגם) → Retopo ל-10 אלף מרובעים → Mixamo (Standard Skeleton 65, T-pose) → FBX → המרה ל-GLB (FBXLoader + GLTFExporter, `gltf-transform weld` ו-`webp`). שמות העצמות `mixamorig…` (אצבעות כולל), קוד המורה מסתמך עליהם.
- **שני מורים:** `male.glb` ו-`female.glb` (~2 MB). לכל דמות `fit` ב-`lib/teachers.js` (קנה מידה והזזת הגיטרה – לאישה זרועות קצרות יותר, אז הגיטרה קרובה יותר).
- **להוסיף מורה חדש:** לייצר GLB באותו תהליך, לשים ב-`public/teachers/`, להוסיף שורה ב-`TEACHERS` (אפשר `comingSoon: true` עד שמוכן) ולכוון `fit` לפי צילום מסך וביקורת קצות האצבעות.
- ה-CSP (`public/_headers`) כולל `blob:` ב-`connect-src` – בלי זה כרום לא טוען את הטקסטורה שבתוך ה-GLB.
- בחירת המורה: בדף הבית (כרטיסים) ובכותרת בשיעורים (כפתור האדם).

## התאמת הגיטרה לדמות
- `fit` ב-`lib/teachers.js` לכל מורה ולכל סוג גיטרה (`fit.classical` / `fit.electric`: `dx dy dz tilt yaw`) + `shrug`/`scale` כלליים. הכיול נעשה לפי בדיקת חדירה: `teacher._debug.penetration()` מחזיר, לקודקודי העור אחרי השלד מול גוף הגיטרה, `depthCm` (כמה עמוק נכנס) ו-`gapCm` (הרווח הקטן ביותר מהגב). יעד: בלי חדירה ורווח עד 1.5 ס"מ. כל שינוי בדגם גיטרה, מורה או יד ימין – להריץ שוב.
- לבדיקה בדפדפן: `window.__MT_DEBUG = true` לפני הטעינה חושף את הבמה ב-`window.__mtStage`.

## הרצה ובדיקה
`cd music_teacher/web && npm install && npm run dev` · בדיקות: `npm test` · בנייה: `npm run build`.
כללים: טלפון + מחשב + מצב לילה (`bg-card` / `bg-page`), `useEffect` עם סוגריים, הערות בעברית.
שינוי בדגם או במצלמה: לבדוק בדפדפן (Playwright עם `--use-gl=swiftshader`).

## עלייה לאוויר
`.github/workflows/music-teacher.yml` – בדיקות ובנייה בכל PR; אחרי מיזוג ל-main עולה ל-Cloudflare Pages (פרויקט `music-teacher`, נוצר אוטומטית בריצה הראשונה).
המיקרופון עובד רק בכתובת מאובטחת (https) ואחרי אישור המשתמש; הכותרות ב-`web/public/_headers`.
