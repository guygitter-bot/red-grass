# מאגר AI

מקום אחד לכל החומר על בינה מלאכותית: מדביקים קישור (כתבה, סרטון, פוסט, כלי) או מעלים קובץ,
ו-Claude קורא אותו, כותב תקציר קצר בעברית ומכניס אותו לקטגוריה לפי הנושא.

כתובת: **https://ai-maagar.pages.dev** (Cloudflare Pages, `.github/workflows/ai-maagar.yml`).

## מה יש

- **הוספה** – תיבה אחת: קישור, כמה קישורים בבת אחת (כל אחד נשמר לחוד), או טקסט חופשי (טיפ, פרומפט) שנשמר כפתק.
  טקסט שליד קישור נשמר כהערה שלו. אותו קישור פעמיים – לא נשמר שוב.
- **קבצים** – PDF, תמונות, טקסט / Markdown / CSV, עד 10MB. במחשב אפשר לגרור לתיבה. תמונה גדולה מוקטנת במכשיר.
  קבצים אחרים (Word וכו') נשמרים, וממופים רק לפי השם.
- **שיתוף מהטלפון** – אחרי "הוספה למסך הבית" (אנדרואיד) האפליקציה מופיעה בתפריט "שיתוף"; הקישור נכנס לתיבה ומחכה ל"הוספה".
- **המיפוי** – רץ ברקע בשרת (אפשר לסגור את האפליקציה): כותרת, תקציר, עד 5 נקודות עיקריות, סוג (כתבה / סרטון / כלי...),
  תגיות וקטגוריה. הסוכן מעדיף קטגוריה קיימת ופותח חדשה רק כשאין מתאימה (הצעות התחלתיות: `STARTER_CATEGORIES` ב-`api/ai.js`).
  דף שלא נפתח מהשרת (רשתות חברתיות) – הסוכן קורא אותו בעצמו (web_fetch). עומס – ניסיון חוזר אחרי דקה (עד 3 פעמים).
- **סידור ידני** – בכל פריט: העברה לקטגוריה אחרת (או חדשה), הערה, "מיפוי מחדש", מחיקה.
  בקטגוריה: "שינוי שם" (שם של קטגוריה קיימת = איחוד).
- **חיפוש** בכותרות, תקצירים, תגיות, הערות וקישורים. **מצב לילה**, טלפון ומחשב.

## איך זה בנוי

- `web/` – React + Vite + Tailwind. כל הצבעים ב-`src/index.css` (משתנים שמתחלפים במצב לילה).
- `api/` – Cloudflare Worker "ai-maagar-api" עם Durable Object אחד (`library.js`) שבו כל הפריטים, הקבצים (בחתיכות) והקטגוריות.
  ההוספה שומרת מיד, ו-alarm של ה-Durable Object ממפה ברקע. קריאת הדף: `source.js`; הסוכן: `ai.js` (`claude-opus-5-5`, effort נמוך).
- כניסה בסיסמה (פעם אחת בכל מכשיר). 10 סיסמאות שגויות נועלות לרבע שעה.

## הגדרה (פעם אחת)

ב-GitHub: **Settings → Secrets and variables → Actions**:

| סוד | מה |
| --- | --- |
| `AI_MAAGAR_PASSWORD` | הסיסמה לכניסה. אם אין – משתמשים ב-`OWNER_PASSWORD` (של mat-kon) |
| `ANTHROPIC_API_KEY`, `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` | כבר קיימים |

אחרי שינוי הסיסמה: Actions → ai-maagar → Run workflow.

## בדיקה

- `cd ai_maagar/api && npm test`
- `cd ai_maagar/web && npm test && npm run build` (מול שרת מקומי: `VITE_API_URL=...`)
