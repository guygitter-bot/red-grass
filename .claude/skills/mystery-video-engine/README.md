# מנוע עריכה לסרטוני ביקורת (לקוח סמוי)

מנוע שמשתלב **בתוך מערכת קיימת**: המערכת מעלה חומר גלם, ומקבלת בחזרה סרטון ערוך של 7–8 דקות.
המשתמש יכול לסמן בטיימליין קטעים שחייבים להיכנס, ואת השאר בוחר המנוע.

## איך זה עובד

```
job.json ──► 1. תמלול (של המערכת, או Whisper כגיבוי)
             2. דפי תמונות ממוזערות ("עיניים": כניסה / ישיבה בעמדה / יציאה)
             3. Claude – קריאה אחת: מה נכנס, כתוביות לנציג/ה, כרטיסי שימור/שיפור, סיכום   → raw_plan.json
             4. אכיפה בקוד: קטעי חובה, אורך, שתי קבוצות כרטיסים, כתוביות רק לנציג/ה      → render_plan.json
             5. גרפיקה (שקופית פתיחה + סיכום) ובנייה ב-ffmpeg                              → video.mp4
```

| קובץ | מה הוא עושה |
|---|---|
| `engine/run.py` | הצינור המלא. `python3 run.py job.json OUT_DIR` |
| `engine/planner.py` | בונה ושולח את הבקשה ל-Claude (`build_request` / `call_claude`) |
| `engine/plan_prompt.md`, `engine/plan_schema.json` | ההנחיות ל-Claude ומבנה התשובה – אפשר לשלוח אותם מכל שפה |
| `engine/validate.py` | אוכף את הכללים ובונה תוכנית רינדור |
| `engine/render.py`, `engine/graphics.py`, `engine/text_he.py` | הבנייה: כתוביות, כרטיסים, שקופיות, מעברים |
| `engine/thumbs.py` | דפי תמונות ל-Claude + פס תמונות לטיימליין במערכת (`timeline_sprite`) |
| `engine/transcribe.py` | גיבוי בלבד: Whisper כשאין תמלול מהמערכת |
| `tests/test_validate.py` | בדיקות לאכיפה (`python3 tests/test_validate.py`) |

## הקלט – `job.json`
דוגמה מלאה: `job.example.json`. זמנים תמיד **בשניות מתחילת חומר הגלם**.

| שדה | חובה | הסבר |
|---|---|---|
| `video` | ✓ | נתיב לחומר הגלם |
| `report` | ✓ | הטקסט המלא של הדוח (ציונים, תשובות, הסיכום המילולי) |
| `score` | | הציון למסך הסיכום |
| `transcript` | מומלץ | התמלול של המערכת: `[{start, end, text, speaker?}]` (או `{"segments": [...]}`). בלי זה – Whisper (איטי, ~3GB) |
| `transcript_offset` | | שניות להוספה לזמני התמלול. 0 אם התמלול נעשה מהקול של הסרטון עצמו; אחרת – ההפרש בין תחילת ההקלטה לתחילת הסרטון (חיובי אם ההקלטה התחילה אחרי הסרטון) |
| `transcript_rep_only` | | `true` אם המערכת שולחת תמלול **של הנציג/ה בלבד** (בלי הדוגם). אז כל שורה היא של הנציג/ה, וכתובית שלא נופלת על שורה מהתמלול נזרקת. עדיף לשלוח את שני הדוברים מסומנים – שאלות הדוגם עוזרות למצוא את הרגעים ("שאל על אחריות") |
| `rep_speaker` | | אם בתמלול יש תוויות דוברים – התווית של הנציג/ה. אז כתוביות של אחרים נזרקות בקוד |
| `must_include` | | הקטעים שהמשתמש סימן בטיימליין: `[{start, end}]`. תמיד נכנסים במלואם |
| `markers` | | `entry_start`, `desk_start`, `exit_end` – אם המשתמש סימן. אחרת Claude מוצא מהתמונות |
| `vocabulary` | | מילים מהתחום לתיקון כתיב |
| `branding` | | `intro_lines` (המלל בשקופית הפתיחה, בדיוק), `logo_top`, `logo_bottom` (PNG שקוף), `photo` (תמונה לשקופית; בלי – פריים מהסרטון) |
| `output` | | `size`, `target_min`/`target_max` (שניות, ברירת מחדל 420–480), `sub_bottom` (מרחק הכתוביות מהתחתית בפיקסלים) |
| `model`, `effort` | | ברירת מחדל `claude-opus-5-5`, `high` |

## הפלט – בתיקיית הפלט
- `video.mp4` – H.264 yuv420p (מתנגן בכל טלפון), 1280x720.
- `raw_plan.json` – מה ש-Claude בחר (קטעים עם סיבה ועדיפות, כתוביות, כרטיסים, סיכום, הסמנים שמצא).
- `render_plan.json` – התוכנית הסופית אחרי האכיפה. **אפשר להציג אותה בטיימליין**, לתת למשתמש לשנות, ולבנות מחדש בלי Claude:
  `python3 run.py job.json OUT --plan raw_plan_after_edit.json`.
- `result.json` – `{video, length_seconds, clips, warnings}`. `warnings` – מה לא הסתדר (למשל: קטעי החובה לבד ארוכים מ-8 דקות – לא חותכים אותם, רק מתריעים).

## הטיימליין במערכת
- פס תמונות לגלילה: `thumbs.timeline_sprite(video, out_dir, every=2)` → `sprite.jpg` + `sprite.json` (`{every, width, height, count}`): תמונה `i` מתחילה בשנייה `i*every`.
- המשתמש מסמן טווחים → `must_include`. אפשר גם סמנים (כניסה / ישיבה / יציאה) → `markers`.
- אחרי העריכה אפשר להציג את `render_plan.json` על אותו טיימליין (מה נבחר ולמה – `reason` ב-`raw_plan.json`).

## התקנה
- **שרת "רגיל"** (מכונה / קונטיינר / תור משימות) – לא serverless קצר: ffmpeg ו-Python, ועבודה של כמה דקות.
- `apt install ffmpeg libraqm0` · `pip install -r requirements.txt` (Whisper רק אם אין תמלול: `pip install openai-whisper`).
- `ANTHROPIC_API_KEY` במשתני הסביבה של השרת (לא בקוד).
- להריץ ברקע ולהודיע כשהסרטון מוכן (callback / polling ל-`result.json`).

## זמן ועלות (הערכה)
- בנייה: ~5–6 דקות לסרטון של 8 דקות על 4 ליבות. Claude: בערך 1–3 דקות. בלי Whisper – אין שלב תמלול.
- Claude Opus 5.5: בערך ‎$0.3–1 לסרטון (תמלול של 15 דק׳ + 2 דפי תמונות + תשובה). להפחתה: `effort: "medium"`.

## מה Claude מקבל ומה הקוד אוכף
ההנחיות המלאות ב-`engine/plan_prompt.md`. Claude בוחר; הקוד מוודא: קטעי חובה שלמים, חפיפות מתאחדות, אורך (מוריד עדיפות 3 ואז 2,
לעולם לא חובה), כתוביות רק בתוך קטעים ורק לנציג/ה (כשיש תוויות דוברים), בדיוק שתי קבוצות של 3–4 כרטיסים בתוך קטע, כניסה ויציאה בפנים.
בלי תוויות דוברים Claude מחליט לפי התוכן – פחות מדויק; מומלץ שהתמלול של המערכת יכלול דוברים (הפרדת דוברים / diarization) ושה-job יציין מי הנציג/ה (`rep_speaker`).
**תזמון:** כתוביות מוצגות לפי זמני התמלול. אם התמלול נעשה מקובץ קול נפרד ולא מהסרטון – לבדוק שהזמנים תואמים, ואם לא, `transcript_offset`.
