# mystery-video – סרטון ביקורת לפי דוח

ממצלמה נסתרת של ביקור בחנות (בדרך כלל 10–20 דקות) + דוח ביקורת → סרטון ערוך של **7–8 דקות**.
הכול רץ כאן, בלי שירות בתשלום (Whisper + ffmpeg + Pillow). **הסרטון והדוח לא נכנסים למאגר** (המאגר ציבורי,
יש בהם פנים ושמות של עובדים) – עובדים רק בתיקיית ה-scratchpad ושולחים עם `SendUserFile`.

## מה המשתמש קבע (לא לשנות בלי שיבקש)
- **אורך 7–8 דקות.** כולל **הכניסה לחנות** (הליכה בקניון ← נכנסים) ו**היציאה** (אחרי "ביי" עד הסוף).
- **בחירת הקטעים לפי הדוח**, בסדר של הביקור: קבלת פנים · בירור צרכים (תקציב, מכשיר נוכחי, גודל מסך) ·
  המלצה והסבר טכני · מוצרים משלימים / מבצעים · טרייד-אין · אחריות ושירות · התנגדויות · הסגירה · פרידה.
  כל דבר שהדוח מציין (חיובי או החמצה) – לנסות להראות את הרגע שלו.
- **מעברים מדורגים** (דעיכה 0.6 שנ' בתמונה ובקול), לא חיתוך גס. לחתוך בין משפטים, עם ~0.4 שנ' מרווח.
- **כתוביות:** לבן עם קו מתאר שחור דק, במרכז התחתית מעל חותמת הזמן הצהובה, עד 2 שורות.
  **רק מה שהנציג/ה אומר/ת** – לא הדוגם המצלם. בלי כתובית למשפט שלא הבנת בוודאות.
- **כרטיסי שימור/שיפור** (כחול סמסונג; ✓ ירוק = שימור, ↑ כתום = לשיפור), **קטנים, בשתי קבוצות בלבד**:
  1. קבוצה של 3–4 **לפני הישיבה בעמדה** (סוף שלב הרצפה – לרוב ברגע בחירת הצבע/דגם).
  2. קבוצה של 3–4 **לקראת סוף הישיבה בעמדה** (לרוב בזמן ההתנגדות / לפני הפרידה).
  כל קבוצה נכנסת כרטיס אחרי כרטיס (0.35 שנ' ביניהם) ונשארת ~20 שנ'. ניסוח קצר (עד ~6 מילים), מתוך הדוח.
- **שקופית פתיחה** (5 שנ'): לבנה ומודרנית, לוגו סאני למעלה משמאל, ZoomAct למטה משמאל, תמונה במסגרת מעוגלת מימין.
  **המלל בדיוק כמו בשקופית של הלקוח:** "ביקור חווית לקוח" / "ביג פאשן SAMSUNG" / "<עיר>" / "<חודש שנה>"
  (את שם הסניף והחודש – מהדוח: "שם סניף מקוצר", תאריך הביקור). אם המשתמש שלח שקופית – להעתיק ממנה את המלל אות באות.
- **מסך סיכום** (12 שנ'): "סיכום הביקור", הציון, עמודת שימור ועמודת לשיפור (4–5 בכל אחת).
- **פורמט:** MP4 H.264 **yuv420p** (yuv444p לא מתנגן בטלפונים!), 1280x720.

## שלבים
```bash
# SK = תיקיית scripts שליד הקובץ הזה (כל מחשב שם אותה במקום אחר – למצוא אותה, לא לנחש)
SK=$(dirname "$(find "$PWD" ~/.claude /home -path '*mystery-video/scripts/render.py' 2>/dev/null | head -1)")
W=<scratchpad או תיקייה זמנית>/mv && mkdir -p $W/src && cd $W
```
1. **התקנה (פעם בשיחה, ברקע):** `pip install -q openai-whisper librosa` (מתקין torch, כמה דקות).
   huggingface חסום – לכן Whisper של OpenAI ולא faster-whisper.
2. **הורדה:** `bash $SK/fetch.sh "<קישור דרייב>" $W/src` → `OUTPUT: <קובץ>`. אם נכשל – לבקש שהקישור ישותף "לכל מי שיש לו את הקישור".
   אודיו: `ffmpeg -v error -y -i SRC -ac 1 -ar 16000 audio.wav`.
3. **מפה של כל הסרטון** (ברקע, ~0.9× מאורך הסרטון): `python3 $SK/transcribe.py audio.wav full.json` → לקרוא את `full.json.txt`.
4. **תמונות ממוזערות** כל ~6 שנ' (ffmpeg + drawtext עם המספר בלבד, רשת עם Pillow) כדי למצוא:
   הכניסה לחנות, **הרגע שמתיישבים בעמדה** (רואים דלפק/מסך/סורק מקרוב), והיציאה.
5. **בחירת קטעים** לפי הדוח (סה"כ ~7:30 כולל פתיח וסיכום, פחות 0.6 שנ' לכל מעבר). קטעים צמודים – לאחד לקטע אחד.
6. **תמלול מדויק רק של הקטעים שנבחרו** (ברקע): `ranges.json` = `[[s,e],...]`,
   `python3 $SK/transcribe.py audio.wav sel.json --model large-v3 --ranges ranges.json`.
7. **כתוביות – רק הנציג/ה:** לבנות טיוטת plan, ואז `python3 $SK/pitch.py audio.wav plan.json`
   (קול גבוה ~190+ / נמוך ~160-). לשלב עם התוכן: מי שואל "כמה זה?" / "מה אני מקבל?" = הדוגם; מי מסביר/מציע = הנציג/ה.
   לתקן ידנית שגיאות תמלול לפי ההקשר ומילים מהדוח (סמסונג, כבל, מטען, טרייד-אין, סאני 360, יבואן רשמי...).
   משפט מעורב ("– שאלה  – תשובה") – להשאיר רק את חלק הנציג/ה עם הזמן שלו.
8. **גרפיקה:**
   - תמונה לפתיח: פריים נקי מהסרטון שרואים בו מוצרים/שלט סמסונג (`python3 $SK/graphics.py frame photo.jpg SRC 54`),
     או תמונה שהמשתמש שלח.
   - `python3 $SK/graphics.py intro intro.png photo.jpg "ביקור חווית לקוח" "ביג פאשן SAMSUNG" "ירכא" "נובמבר 2026"`
   - `summary.json` = `{"keep":[...], "fix":[...], "score":"77.42"}` → `python3 $SK/graphics.py outro outro.png bg.jpg summary.json`
     (`bg.jpg` = פריים מהעמדה).
   - **להסתכל** על שתי התמונות (Read) לפני שממשיכים.
9. **plan.json** (המבנה בראש `render.py`): פתיח → כניסה → קטעים → (כולל יציאה) → סיכום.
   כרטיסים: `{"t": <זמן במקור>, "end": <זמן במקור>, "kind": "keep"|"fix", "text": "..."}` – קבוצה = 4 כרטיסים עם t עולה ב-0.35.
10. **רינדור** (ברקע, ~10–20 דקות): `python3 $SK/render.py SRC plan.json out/video.mp4`.
11. **בדיקה לפני שליחה:** פריימים בפתיח, באמצע מעבר, בכל קבוצת כרטיסים, בכתובית של 2 שורות וביציאה (רשת אחת, Read).
    `ffprobe` – לוודא `yuv420p`. שגיאה בכרטיסים חופפים / כתובית הפוכה – לתקן ולרנדר שוב.
12. **שליחה:** `SendUserFile` (status normal). לענות בעברית פשוטה וקצרה: אורך, מה נכנס (לפי סעיפי הדוח), איפה הכרטיסים,
    ומה כדאי לוודא (מספרים ושמות בכתוביות – תמלול אוטומטי שתוקן ביד). לא לבקש כסף/מפתחות – הכול חינמי ורק מהמכסה.

## הערות
- הלוגואים ב-`assets/` נחתכו משקופית ששלח המשתמש (לא חדים במיוחד). אם ישלח קובצי לוגו מקוריים – להחליף שם (PNG שקוף).
- שלבי ההמתנה (התקנה, תמלול, רינדור) – תמיד ברקע (`run_in_background`), לא לחכות בפקודה רגילה (מגבלה של 10 דקות).
- לא להשתמש ב-`drawtext` של ffmpeg לעברית (הופך את הטקסט) – רק `text_png` מ-`video-tools/lib.py`.
