# כלי עריכת וידאו – מדריך קצר

מצרפים סרטון (או כמה) בצ'אט עם Claude, כותבים פקודה קצרה – וחוזר סרטון ערוך.
אין צורך להסביר איך. אפשר להוסיף בקשה חופשית בעברית אחרי הפקודה.

| פקודה | מה היא עושה | דוגמה |
|---|---|---|
| `/color-grade` | צבעוניות קולנועית אחידה (טורקיז-כתום). אפשר גם "חם", "נקי", "שחור לבן" | מצרפת 3 קליפים ← `/color-grade קולנועי` |
| `/beats-and-cuts` | חיתוכים על הביט של שיר, זום קטן על הקצב, בפורמט אנכי | מצרפת קליפים + שיר ← `/beats-and-cuts` |
| `/before-and-after` | סרטון "לפני / אחרי" עם קו שנע על המסך | סרטון אחד ← `/before-and-after` (משווה לגרסה עם צבעוניות) |
| `/hand-drawn` | הופך לציור עיפרון על נייר שמצטייר, עם כותרת שנכתבת | `/hand-drawn כותרת: הרעיון שלי` |
| `/motion-graphics` | כותרות מונפשות ומעברים בסגנון שואוריל | `/motion-graphics "ברוכים הבאים" "מי אנחנו" "בואו נתחיל"` |

## טיפים
- צרפי את הקבצים **באותה הודעה** עם הפקודה.
- אפשר לבקש שינוי אחרי: "יותר חם", "חתיכים כל ביט", "קווים עבים יותר", "צבע ירוק".
- הפלט חוזר כקובץ וידאו להורדה. אם יצא משהו לא טוב – כתבי מה לשנות ונריץ שוב.

## למי שמתחזק (טכני)
- `lib.py` – עזרים משותפים: ffprobe, ffmpeg, טקסט עברי ל-PNG (Pillow + raqm), שמות קבצי פלט.
- `fonts/Rubik.ttf` – פונט עברי (רישיון SIL OFL, `fonts/OFL.txt`).
- כל סקיל = תיקייה ב-`.claude/skills/<שם>/` עם `SKILL.md` וסקריפט פייתון. פלט ברירת מחדל: `/tmp/video-out` (או `$VIDEO_OUT_DIR`).
- ffmpeg לא תומך בעברית מימין לשמאל, לכן כל טקסט עברי מצויר ל-PNG (או ב-Chromium) ומודבק על הסרטון.
- `motion-graphics` דורש node + playwright (מותקנים בסביבת הענן).
