# חנוכה לילדים

אפליקציה בעברית (מימין לשמאל) לילדים בני 9-11: סיפור החג, מנהגים, חידון, משחקים ותוספות.
בלי שרת ובלי בקשות רשת – הכול רץ בדפדפן, וההתקדמות נשמרת ב-localStorage של המכשיר.
עובדת בטלפון ובמחשב, ובמצב לילה (ברירת מחדל: לפי המכשיר).

## מה יש בה
- **דף הבית** – חנוכייה מונפשת עם הנרות של הערב ("הערב מדליקים נר רביעי" או "עוד X ימים לחנוכה"), מונה כוכבים, עובדה של היום.
- **סיפור החנוכה** – 7 פרקים קצרים עם שאלת הבנה בסוף כל פרק (כוכב על כל פרק).
- **מנהגי החג** – הדלקה, ברכות, חנוכייה מול מנורה, מאכלים, סביבון, דמי חנוכה, תאריכים.
- **חידון** – 39 שאלות בשלוש רמות (קל, בינוני, אלוף). סיבוב = 8 שאלות, עם הסבר אחרי כל תשובה ושיא לכל רמה.
- **משחקים** – סביבון נגד המחשב, זיכרון (3 גדלים), הדלקת החנוכייה, תפוס את הסופגניות, מילה מבולבלת.
- **תוספות** – הידעת?, חידות, ברכות וטקסטים מסורתיים, מתכון ללביבות (עם מבוגר), כרטיס ברכה, תגים.
- צליל (WebAudio, מופעל רק אחרי לחיצה), מצב לילה/יום, כיבוד `prefers-reduced-motion`.

## מבנה התיקיות
```
hanukkah/web/
  public/            manifest, אייקון SVG, theme-boot.js, _headers
  src/
    App.jsx          ניווט לפי hash (#/story, #/games/dreidel ...)
    context.jsx      התקדמות, כוכבים והודעת תג חדש
    index.css        צבעים (bg-card / bg-page ...) ומצב לילה
    components/      חנוכייה (SVG), כותרת, אריחים
    screens/         מסך לכל חלק
    data/            כל התוכן: סיפור, מנהגים, שאלות, עובדות, חידות, מילים, טקסטים, מתכון
    lib/             לוגיקה טהורה עם בדיקות: תאריכים, סביבון, הדלקה, תפיסה, זיכרון, התקדמות, תגים
```

## כללים
- תוכן חדש נכנס ל-`web/src/data/`. שירים: רק טקסטים מסורתיים או בנחלת הכלל (בלי מילים של שירים מודרניים).
- שדה חדש בהתקדמות – ברירת מחדל ב-`safeProgress` (`lib/progress.js`), כדי שנתונים ישנים ימשיכו לעבוד.
- תאריכי החג: `lib/dates.js` (`FIRST_NIGHTS`, הנר הראשון בערב של התאריך). להוסיף שנים חדשות לפני שנגמרת הרשימה (2030).

## בדיקה והרצה
```
cd hanukkah/web
npm install
npm test            # בדיקות
npm run build       # בנייה
npm run dev         # פיתוח
```
