# חשבון לכיתה ד' – תרגול למבחן

תרגול לילדים לפי רשימת הנושאים של המורה (18 נושאים, מספרים עד 10,000). בנוי כמו `english_words/`: HTML+JS בלי בנייה, שרת קטן, וניהול להורים.

- **19 נושאים בשישה פרקים** (`web/public/topics.js` – המקור היחיד): מספרים טבעיים ופעולות חשבון (סדרות, בניית מספרים, ארבע פעולות, סדר פעולות, אפס ואחד, משמעות הכפל, בעיות מילוליות, כתיבת שאלה לתרגיל), שברים (השוואה, גדול/קטן משבר, השלמת השלם), מדידות אורכים, גיאומטריה (מקבילות, היקף, שטח, זוויות, אלכסונים), חקר נתונים (דיאגרמות), ופרק אחרון **📝 דף התרגול של המורה** (`teacher_sheet`, פתוח מההתחלה): שאלות מהסוגים שבדף התרגול שהמורה שלחה (סדרות בשלישיות וציר מספרים, ספרות, 0 ו-1 משולבים, השוואת מכפלות עם < > =, בעיות מילוליות רב-שלביות, שברים וזמן, רשתות משבצות, מקבילית, אלכסון מקווקו, עיפרון על סרגל). הוריאנטים האלה נמצאים גם בתוך הנושאים הרגילים, והמחולל של הנושא `teacher_sheet` מערבב את כולם (`gen/sheet.js`).
- **סיבוב** = 10 שאלות אקראיות, צריך 80% בתשובה ראשונה כדי לעבור, אחרת סיבוב חדש. טעות מראה את התשובה הנכונה והסבר קצר, וממשיכים. תשובה נכונה = כוכב.
- **פתיחה הדרגתית** בתוך כל פרק: עוברים נושא ← נפתח הבא. הפרקים עצמם פתוחים. **🎓 מבחן מסכם** בנוי **לפי דף התרגול של המורה**: 34 שאלות בסדר הדף (21 שאלות, חלקן עם סעיפים א-ה, כמו "שאלה 4 ב"), בלי ערבוב, עם מספרים חדשים בכל פעם. כל שאלה שומרת את הנושא האמיתי שלה (`gen/sheet.js`, `EXAM_STEPS`). פתוח תמיד ומודגש אחרי שעברו הכול.
- **השאלות** (`web/public/gen/*.js`): פונקציות טהורות עם מחולל מספרים עם זרע (`rand.js`) שמחזירות `{ text, expr?, svg?, options?, answer, explain }`. קובץ לכל פרק (`numbers`, `fractions`, `measure`, `geometry`, `data`), ציורי SVG ב-`svg.js` (בצבעי משתני CSS – מתאים למצב לילה). `rich.js` שומר על מספרים משמאל לימין ומציג שברים עומדים.
- סיבוב שלא הסתיים נשמר בטלפון לכל נושא (`cd-progress`, לפי זרע – אותן שאלות בדיוק). כל סיבוב שהסתיים נשלח לשרת (`report.js`, עם תור כשאין רשת). בכניסה הראשונה הילד כותב שם.
- **ניהול להורים** (`admin/public`, Pages `cheshbon-admin`): לכל ילד – עבר 80%? אחרי כמה ניסיונות, הכי טוב/ממוצע/אחרון לכל נושא, הנושאים והשאלות הכי קשים (גם לפי המבחן המסכם), וכל הסיבובים. הכניסה הראשונה קובעת סיסמה (מוצפנת; 10 טעויות = נעילה לרבע שעה).
- **שרת** (`api/`, Worker `cheshbon-api`, Durable Object `Tracker` אחד): `/round` מהאפליקציה, `/admin/*` עם סיסמה. כתובת השרת ב-`config.js` – זהה ב-`web` וב-`admin` (ה-workflow בודק).
- עלייה: `web/public` → https://cheshbon-dalet.pages.dev (`cheshbon.yml` אחרי מיזוג ל-main).
- בדיקה: `cd math_test/api && npm test` · `cd math_test/web && npm test` · `cd math_test/admin && npm test`. הבדיקות מייצרות 300 שאלות לכל נושא ובודקות תשובות, מסיחים וחישובים.
- סוג תרגול חדש: להוסיף ל-`TOPICS` ב-`topics.js`, מחולל ב-`gen/`, ל-`MODES` ב-`api/stats.js` ול-`SECTIONS` ב-`admin/public/view.js` (בדיקה מוודאת שהרשימות זהות).
