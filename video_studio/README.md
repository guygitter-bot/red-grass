# סטודיו – עריכת וידאו בדפדפן (`video_studio/`)

עורך וידאו מלא שרץ במחשב שלך (localhost) ונפתח בדפדפן – במחשב ובטלפון. תחליף מקומי ל-CapCut:
שום דבר לא עולה לענן, והייצוא נעשה ב-ffmpeg באיכות מלאה מהקבצים המקוריים.

## הפעלה

צריך פעם אחת: [Node.js 20+](https://nodejs.org) ו-[ffmpeg](https://ffmpeg.org/download.html) (ב-Mac: `brew install ffmpeg`).

```bash
cd video_studio
npm install     # פעם אחת (מתקין את מנוע התמלול)
npm start
```

- במחשב: http://localhost:4747
- בטלפון (אותו Wi-Fi): הכתובת שמודפסת בהפעלה (`http://<כתובת המחשב>:4747`), ואז "הוספה למסך הבית".
- הפרויקט והקבצים נשמרים ב-`video_studio/data/` (לא נכנס ל-git).

הגדרות (משתני סביבה): `PORT` (4747), `STUDIO_DATA` (תיקיית הנתונים), `STUDIO_PROXY=webm` (לדפדפן בלי H.264),
`STUDIO_WHISPER_MODEL` (מודל תמלול אחר מ-Hugging Face), `STUDIO_MODEL_DIR` (מודלים שכבר בדיסק, בלי אינטרנט).

## API ו-MCP

```bash
claude mcp add --transport http video-studio http://localhost:4747/mcp
curl -X POST http://localhost:4747/api/split -H "Content-Type: application/json" -d '{"time": 3.5}'
curl -X POST "http://localhost:4747/api/upload?name=clip.mp4" --data-binary @clip.mp4
```

הרשימה המלאה: כפתור "API · MCP" בממשק, או `GET /api/actions`. מה שסוכן עושה מופיע מיד בממשק ואפשר לבטל אותו.
אבטחה: השרת מיועד לרשת הביתית. דף אינטרנט זר לא יכול לשלוח אליו פקודות (בדיקת Origin), וייבוא קובץ לפי נתיב מותר רק מהמחשב עצמו.

## מבנה

- `server/index.js` – שרת HTTP: קבצים, API, MCP, עדכונים חיים (SSE).
- `server/actions.js` – **כל הפעולות במקום אחד**; מהן נבנים ה-API, כלי ה-MCP והרשימה שבממשק. פעולה חדשה מוסיפים כאן.
- `server/edit.js` – פעולות העריכה הטהורות (פיצול, מחיקה, טווח, שתיקות, כתוביות) + בדיקות ב-`test/`.
- `server/store.js` – מצב הפרויקט, שמירה, ביטול / חזרה. `server/media.js` – קליטת קבצים, גרסת תצוגה, גל קול, זיהוי שתיקות.
- `server/export.js` – בניית פקודת ffmpeg. `server/ass.js` – טקסטים וכתוביות כ-ASS (libass יודע עברית מימין לשמאל).
- `server/transcribe.js` – Whisper מקומי (transformers.js). `server/sfx.js` – סינתזה של ספריית הסאונד. `server/presets.js` – סגנונות.
- `web/` – הממשק, בלי שלב בנייה: `app.js`, `timeline.js`, `player.js`, `panels.js`, `state.js` (כולל התרגומים).
- `fonts/` – גופנים עבריים ברישיון OFL; אותם קבצים משמשים את התצוגה ואת הייצוא.

**הטקסט בתצוגה ובייצוא מצויר פעמיים** (`web/player.js` ב-CSS, `server/ass.js` ב-libass) – שינוי בסגנון מחייב שינוי בשניהם.

## בדיקה

`npm test`. לשינוי במסך: להריץ עם `STUDIO_PROXY=webm` (ל-Chromium של הסביבה אין H.264) ולבדוק עם Playwright.
