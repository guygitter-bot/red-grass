# סרטון נדל״ן

כלי למשווקי נדל״ן: מעלים צילום של בניין (או הדמיה קיימת) ו/או שרטוט (חזית, סקיצה, תוכנית דירה), ומקבלים סרטון תדמית –
4 שוטים קולנועיים של 8 שניות, עם שם הפרויקט בפתיחה ופרטי קשר בסיום. בעברית (RTL), לטלפון ולמחשב, עם מצב לילה לפי המכשיר.

- האפליקציה: https://nadlan-video.pages.dev (`web/`, React + Vite + Tailwind)
- השרת: `nadlan-video-api` (`api/`, Cloudflare Worker + Durable Object קטן `Studio`)
- עלייה לאוויר: אוטומטית אחרי מיזוג ל-main (`.github/workflows/nadlan-video.yml`)
- אותו תהליך מהצ'אט: הסקיל `/nadlan-video` (`.claude/skills/nadlan-video/`), עם הכלים של Creative Claw.

## איך זה עובד

העיקרון שנותן את האיכות: **לא מנפישים שרטוט, ולא נותנים למחולל הווידאו להמציא את הבניין.** כל שוט הוא
תמונת מקור ← פריים פוטוריאליסטי ← אישור ← תנועת מצלמה אחת, איטית.

1. **סרטון חדש** – שם, סוג (בניין / דירה / בית), צילום ו/או שרטוט, אור (שעת זהב / יום / דמדומים), פורמט (16:9 / 9:16).
   התמונות מוקטנות בטלפון (עד 1920 פיקסלים) ונשמרות **רק במכשיר** (IndexedDB).
2. **הבמאי** (`POST /plan`) – Claude (`claude-opus-5-5`) מסתכל על התמונות וכותב 4 שוטים: פתיחה, התקרבות, רגע של אווירה, סיום.
   לכל שוט: כותרת והסבר בעברית, הוראה באנגלית לפריים, והוראה באנגלית לתנועת המצלמה. הכלל הראשון שלו: נאמנות לבניין
   (מספר קומות, חזית, חלונות, חלוקת החדרים) – מותר להלביש את הסצנה, אסור לשנות את האדריכלות.
3. **פריים** (`POST /still`) – מחולל התמונות של Google הופך את הצילום / השרטוט לפריים הפתיחה של השוט (שרטוט הופך להדמיה
   אדריכלית; תוכנית דירה – למבט מתוך החדר). זול ומהיר, ואפשר לבקש "פריים אחר" עד שמרוצים.
4. **סרטון** (`POST /clip` ← `/clip/status` ← `/clip/file`) – מחולל הווידאו של Google (Gemini Omni, דרך ה-Interactions API) מקבל את
   הפריים כפריים ראשון ויוצר 8 שניות (1080p; בטיוטה 360p). הקריאה ל-Google נשארת פתוחה דקה ויותר, ולכן היא רצה **ברקע**:
   כל סרטון הוא עבודה במופע משלו של ה-Durable Object (`job:<מזהה>`, ב-alarm). האפליקציה שואלת כל 10 שניות, ובסוף מורידה את
   הקובץ דרך השרת ושומרת אותו במכשיר. אפשר לסגור את האפליקציה באמצע – כשחוזרים היא ממשיכה לחכות לאותה עבודה (נשמרת יומיים).
5. **הסרט המלא** – השוטים מנוגנים ברצף על canvas עם כותרת פתיחה, מעברים רכים ושקופית סיום, ואותו ציור מוקלט לקובץ אחד
   (MediaRecorder: mp4 אם הדפדפן יודע, אחרת webm). כל שוט אפשר גם להוריד / לשתף בנפרד, באיכות המקורית.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `api/worker.js` | הכתובות, סיסמה, תקרה יומית, בדיקת הקלט ו-CORS (רק מכתובת האפליקציה) |
| `api/studio.js` | Durable Object: הסיסמה (מגובבת) והמונה היומי (`main`), ועבודת הרקע של כל סרטון (`job:<מזהה>`) |
| `api/brief.js` | סוגים, אור, פורמט (כפול ב-`web/src/lib/brief.js` – בדיקה מוודאת) |
| `api/director.js` | הבמאי: ההנחיות ל-Claude וקריאת רשימת השוטים |
| `api/still.js` | פריימים: ההוראה, הקריאה ל-Google, ומציאת מודל אחר אם השם שבהגדרות כבר לא קיים |
| `api/video.js` | מחולל הווידאו: הבקשה (עם ירידה לבקשה פשוטה יותר אם Google דוחה שדה), קריאת התשובה, והורדת הקובץ |
| `web/src/components/` | `Login`, `Home`, `NewFilm`, `Project` (שוטים + כותרות), `Shot`, `Film` (הסרט המלא) |
| `web/src/lib/` | `api`, `store` (שמירה במכשיר), `shots` (הפקת שוט), `film` (נגן + הקלטה), `image`, `brief` |

## סיסמה ותקרה יומית

סרטון עולה כסף אמיתי אצל Google, ולכן האפליקציה נעולה:
- **סיסמה** – מי שנכנס ראשון קובע אותה (לפחות 6 תווים). נשמרת מגובבת ב-`Studio`. 8 ניסיונות שגויים = נעילה ל-10 דקות.
  לאפס סיסמה שנשכחה: למחוק את המפתח `pass` באחסון של ה-Durable Object (לוח הבקרה של Cloudflare).
- **תקרה יומית** לכל המשתמשים יחד, ב-`api/wrangler.toml`: `DAILY_CLIPS` (24), `DAILY_STILLS` (80), `DAILY_PLANS` (40). פעולה שנכשלה לא נספרת.

## סודות (ב-GitHub, לא בקוד)

- `ANTHROPIC_API_KEY`, `GEMINI_API_KEY` – כבר קיימים במאגר. יצירת וידאו דורשת חיוב פעיל בחשבון Google (https://aistudio.google.com/apikey).

שמות המודלים ב-`api/wrangler.toml` (`IMAGE_MODEL`, `VIDEO_MODEL`). אם Google מחליפה שם, השרת מוצא לבד מודל מתאים ברשימה שלה.

## בדיקה

```
cd nadlan_video/api && npm test
cd nadlan_video/web && npm test && npm run build
```

בדיקה אמיתית מול Google (פריים + סרטון אחד בטיוטה, פחות מדולר): `nadlan-video-probe.yml` (`api/probe.mjs`) – רץ רק כשמשנים
את הקוד שפונה ל-Google, או בהפעלה ידנית.

שינוי במסך: לבדוק בדפדפן עם Playwright ושרת מדומה (לבנות עם `VITE_API_URL=http://localhost:9999` ו-`page.route`).
ה-chromium כאן בלי H.264 – לבדוק עם קטע webm (`ffmpeg ... -c:v libvpx`).

## רעיונות שלא בוצעו

- מוזיקת רקע לסרט המלא (היום רק האווירה שנוצרת עם הסרטון) – צריך קטע עם רישיון מסחרי.
- לוגו של היזם (העלאת תמונה) בפתיחה ובסיום.
- תוכנית ב-PDF ישירות (היום: צילום מסך).
- כמה צילומים של אותו בניין / כמה חדרים, ויותר מ-4 שוטים.
- שוט "מהשרטוט למציאות" (פריים ראשון = השרטוט, פריים אחרון = ההדמיה).
- הרכבת הסרט המלא בשרת (ffmpeg) במקום הקלטה בדפדפן.
- 4K (המחולל תומך), שוטים של עד 15 שניות, ועריכת שוט קיים בבקשה חופשית ("תוסיף עצים").
- כמה משתמשים עם סיסמה לכל אחד, ומעקב עלות לכל משתמש.
