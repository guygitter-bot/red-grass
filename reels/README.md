# רילס – כתוביות בעברית

כלי קטן ששורף כתוביות בעברית לסרטון אנכי (אווטאר מדבר מ-Gemini / HeyGen), לפי הטקסט שהאווטאר אמר.
בלי זיהוי דיבור: הכלי מזהה הפסקות בקול, מחלק את הטקסט לכתוביות קצרות (עד כ-5 מילים) ומתזמן אותן לפי הדיבור.

## הרצה
```
node reels/captions.mjs <סרטון.mp4> <תסריט.txt> [פלט.mp4]
```
- בלי פלט: נוצר `<סרטון>-captions.mp4` ליד הסרטון.
- ליד הפלט נוצר גם קובץ `.srt` עם הכתוביות והזמנים.
- צריך: Node 22 ו-ffmpeg (עם libass). הגופן Rubik Bold נמצא ב-`reels/fonts` (רישיון OFL).

## לתקן כתובית
1. לפתוח את קובץ ה-`.srt` שנוצר (עורך טקסט רגיל), לתקן את הטקסט או את הזמנים ולשמור.
2. להריץ שוב עם ה-srt במקום התסריט – הזמנים נלקחים כמו שהם:
```
node reels/captions.mjs <סרטון.mp4> <קובץ.srt> [פלט.mp4]
```
(שימו לב: אם הפלט הוא אותו שם – ה-srt החדש יידרס, אז כדאי לתת שם פלט אחר או לשמור עותק.)

## עיצוב
גופן Rubik Bold, גובה ≈ 5.5% מגובה הסרטון, לבן עם מסגרת שחורה עבה, באמצע לרוחב, בגובה ≈ 68% (למטה נשאר מקום לממשק של אינסטגרם).
הגדרות (מספר מילים, רגישות לשתיקה, צבעים) בראש `captions.mjs`.

## בדיקות
`node --test reels/captions.test.mjs` (ב-Node 22 צריך לציין את הקובץ, לא רק את התיקייה).
