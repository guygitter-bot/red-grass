# בורסאי – השקעות במניות

אפליקציה אישית למשקיעה מתחילה: נתוני שוק חיים, ניתוח של כל מניה (אחורה וקדימה), המלצות, מעקב אחרי מניות שנקנו,
תיק דמה לתרגול, התראות לטלפון, צ'אט בסגנון ווטסאפ עם AI, ומילון ומדריך למתחילים.

כתובת: **https://bursa-app.pages.dev** (Cloudflare Pages, `.github/workflows/bursa.yml`).
(אם השם תפוס – Cloudflare מוסיף לו סיומת; אז לעדכן את `ALLOWED_ORIGINS` ב-`api/wrangler.toml` ואת הכתובת כאן.)

> **לא ייעוץ השקעות.** אף אחד לא יודע לחזות את השוק בוודאות. האותות והתחזיות הם כלי עזר סטטיסטי.

## מה יש

- **בית** – מדדים חיים (S&P 500, נאסד"ק, ת"א 35, VIX, דולר/שקל, נפט, זהב, ביטקוין), **צפי השוק** מה-AI
  (מהחדשות בעולם, מתעדכן כל 3 שעות), הזדמנויות קנייה ומניות שכדאי להיזהר מהן (מהסריקה), וסיכום התיק.
- **דף מניה** – גרף עם "קונוס" תחזית, ציון -100..100 עם הסיבות, אינדיקטורים מוסברים, תחזית לשבוע/חודש/3 חודשים/שנה
  (טווח של 80%), **בדיקה לאחור** (כמה הכללים עבדו על המניה הזאת ב-5 השנים האחרונות מול "קנה והחזק"), חדשות,
  ו**ניתוח AI** לפי בקשה (עם חיפוש ברשת; נשמר 6 שעות).
- **תיק** – התיק האמיתי (רווח/הפסד בשקלים, סטופ-לוס ויעד), **תיק דמה** (100,000 ₪ וירטואליים, קנייה/מכירה במחיר החי),
  רשימת מעקב, התראות מחיר.
- **צ'אט** – "בורסאי" עונה בעברית פשוטה, עם כלים שמביאים נתונים אמיתיים מהשרת (מניה, שוק, התיק) וחיפוש ברשת.
  מציע מניות ל**רשימת הקניות** (נוספות רק באישור בכפתור). **צ'אט צף** בכל מסך (`FloatingChat.jsx`): מגירה בטלפון, חלון נגרר במחשב,
  מזעור לפס עם ההודעה האחרונה, ובכרום במחשב – "חלון צף מעל הכול" (Picture-in-Picture). הצ'אט משותף: `src/lib/chatStore.js`.
- **התראות לטלפון** (Web Push): אות קנייה חזק, אות מכירה למניה שבתיק, תנועה חדה (ברירת מחדל 5%), סטופ-לוס/יעד,
  התראות מחיר, ירידה/עלייה חדה בשוק, שינוי בצפי השוק. כל נושא לכל היותר פעם ב-12 שעות.
- **ללמוד** – מדריך למתחילים (איך מתחילים להשקיע בישראל) ומילון של 200+ מושגים.

## איך זה בנוי

- `web/` – React + Vite + Tailwind. צבעים ב-`src/index.css`. תוכן: `src/lib/glossary.js`, `src/lib/guide.js`.
- `api/` – Cloudflare Worker "bursa-api" עם Durable Object אחד (`market.js`): כל הנתונים + **המנוע שרץ כל הזמן**
  (alarm כל 2 דקות כשבורסה פתוחה, אחרת כל 20): בכל סבב סורק את המניות שלך ועוד כמה מרשימת הסריקה (`universe.js`),
  שומר אותות ושולח התראות.
  - נתונים: `data.js` – Yahoo Finance (בלי מפתח; לפעמים בעיכוב של 15-20 דקות), חדשות מ-Yahoo ו-Google News.
    מניות בתל אביב: סמל עם `.TA`, המחיר מומר מאגורות לשקלים.
  - ניתוח: `analysis.js` – פונקציות טהורות: SMA/EMA, RSI, MACD, בולינגר, ציון וסיבות, תחזית (תנודתיות + מגמה מכווצת
    לתשואת שוק), בדיקה לאחור.
  - AI: `ai.js` (`claude-opus-5-5` עם fallback): צ'אט עם כלים, צפי שוק, דעה על מניה. מגבלה: 150 הודעות ו-30 ניתוחים ביום.
  - התראות: `push.js` (העתק מ-eretz_ir).
- **סיסמה**: נקבעת בכניסה הראשונה (נשמרת כ-PBKDF2). כל השאר דורש התחברות.

## הגדרה (פעם אחת)

ב-GitHub: **Settings → Secrets and variables → Actions**: `ANTHROPIC_API_KEY`, `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` – כבר קיימים.
אחרי העלייה הראשונה – להיכנס מיד ולקבוע סיסמה.

## בדיקה

- `cd bursa/api && npm test`
- `cd bursa/web && npm test && npm run build` (מול שרת מקומי: `VITE_API_URL=...`)
