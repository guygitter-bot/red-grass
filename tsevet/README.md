# צוות – בוטים של שיווק ב-Telegram

צוות קטן של בוטי AI שעוזרים לשווק את האפליקציות שבמאגר. כולם יושבים בקבוצת Telegram אחת עם "נושאים"
(שיחה נפרדת לכל פרויקט), רואים את אותה שיחה ומעבירים עבודה זה לזה.

| בוט | תפקיד |
|---|---|
| 🎨 קריאייטיב | רעיונות, טקסטים למודעות, תסריטים לסרטונים, תוכן לדף העסקי (שם, תיאור, פוסטים, בריף לתמונות) |
| 📊 קמפיינים | קמפיינים בפייסבוק ובגוגל: מבנה, קהלים, תקציב, מילות חיפוש, מדידה |

## איך זה עובד
- כותבים בקבוצה מה צריך. אם לא פנו לבוט מסוים, מודל קטן (Haiku) מחליט מי עונה ראשון.
  פנייה ישירה: Reply להודעה של בוט, או `@שם_הבוט`.
- בוט יכול להעביר את ההמשך לבוט השני (`handoff`). עד 4 תורות להודעה אחת, ואז עוצרים ("תמשיכו" ממשיך).
- כלים לכל בוט: חיפוש וקריאה ברשת, `app_info` (ה-README של האפליקציה – נבנה מ-`api/build-apps.mjs` בכל עלייה),
  `remember` / `forget` (זיכרון משותף לצוות).
- רק הבעלים מדבר עם הצוות: פעם אחת `/start <TEAM_OWNER_CODE>` בצ'אט פרטי עם אחד הבוטים. אחרים מקבלים "בוט פרטי".
- פקודות: `/costs` (עלות Claude היום/החודש), `/memory`, `/reset` (מתחיל את הנושא מחדש), `/help`.
- תמונות נקראות (Claude רואה אותן). הודעות קוליות – עוד לא.

## שלבים הבאים
- יצירת תמונות וסרטונים (סרטונים מתבנית עם קריינות "נועה" ומוזיקה, כמו `mat_kon/tutorials`).
- חיבור ל-Google Ads ול-Meta Marketing API: קמפיינים נוצרים **מושהים**, הפעלה והוצאת כסף רק בכפתור אישור.
  (פייסבוק לא מאפשרת לפתוח דף עסקי דרך API – הבוט מכין את התוכן והבעלים פותח את הדף.)

## מבנה
- `api/worker.js` – `/tg/<agent>` (עדכונים מ-Telegram, נבדקים בסיסמה שנגזרת מהטוקן) ו-`/setup` (webhook, שם, פקודות).
- `api/team.js` – Durable Object `Team` אחד: תור, שיחות, זיכרון ועלויות. הבוטים רצים ברקע ב-alarm.
- `api/agents.js` – התפקידים, הכלים וההרצה מול Claude. `api/telegram.js` – Bot API.
- עלייה: `.github/workflows/tsevet.yml` אחרי מיזוג ל-main → https://tsevet-api.guygitter.workers.dev, ואז `/setup` מחבר את הבוטים.

## סודות (GitHub → Settings → Secrets → Actions)
`TG_CREATIVE_TOKEN`, `TG_CAMPAIGNS_TOKEN` (מ-@BotFather), `TEAM_OWNER_CODE` (קוד שהבעלים בוחר),
ו-`ANTHROPIC_API_KEY`, `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` שכבר קיימים.

## הקמה בפעם הראשונה
1. ב-Telegram: @BotFather → `/newbot` פעמיים (שם המשתמש חייב להסתיים ב-`bot`). את הטוקנים לשמור כסודות.
2. אחרי העלייה: `/start <הקוד>` בצ'אט פרטי עם אחד הבוטים.
3. קבוצה חדשה → להפעיל "נושאים" (Topics) → להוסיף את שני הבוטים **כמנהלים** (כך הם רואים את כל ההודעות).
