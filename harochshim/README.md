# הרוכשים – אפליקציית ההטבות

"תנו לנו לחסוך בשבילכם". אפליקציה לחברי קבוצת הרכישה: קטגוריות, ספקים בכל קטגוריה והצעות המחיר שלהם.
הלקוח שואל את **העוזר החכם של הספק** (Claude), וכשהוא מוכן – משאיר שם וטלפון והליד נשלח לספק עם סיכום השיחה.
האפיון המלא: `spec.html` (הלוגו: `logo.jpg`).

- **לקוח** – https://harochshim.pages.dev : קטגוריות, חיפוש, הטבות חמות, דף ספק, שיחה עם העוזר, "שיחזרו אליי", "הפניות שלי".
- **ספק** – `#/partner/<סוד>` (קישור אישי שהמנהל יוצר): רואה **רק** את הלידים שלו, מעדכן מצב, סכום עסקה והערה.
- **מנהל (המאסטר)** – `#/admin` בסיסמה: כל הלידים (סינון לפי ספק/חודש, הורדה לאקסל), ספקים (הוספה, עריכה, בנק מידע לעוזר,
  הצעות מחיר עם קובץ PDF/תמונה, קישור לספק, **הורדה מהרשימה** – לא מחיקה, אפשר להחזיר), קטגוריות, עלויות העוזר.

## מבנה
- `api/` – Cloudflare Worker `harochshim-api` + Durable Object `Club` אחד (`club.js`). ניקוי נתונים ב-`model.js`, העוזר ב-`ai.js`.
  - ספק שהורד (`active: false`): לא מוצג, העוזר והקישור שלו לא עובדים; ההצעות והלידים נשמרים.
  - העוזר: `claude-opus-5-5` (effort low, fallback בצד השרת). עונה רק מבנק המידע + ההצעות + עד 4 קובצי הצעה, ומעביר ליד בכלי `ready_for_supplier`.
  - מגבלות: 1500 תשובות עוזר ו-400 לידים ביום; ליד כפול (אותו טלפון לאותו ספק ב-24 שעות) מתעדכן במקום להיפתח מחדש.
- `web/` – React + Vite + Tailwind, RTL, טלפון + מחשב + מצב לילה. צבעי הלוגו ב-`src/index.css` (navy, sky, coral, sun).

## סודות ב-GitHub
`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `ANTHROPIC_API_KEY` (קיימים), ו-`HAROCHSHIM_ADMIN_PASSWORD` – הסיסמה למסך הניהול.
בלי הסיסמה מסך הניהול נעול (השאר עובד).
