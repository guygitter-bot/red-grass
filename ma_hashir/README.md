# מה השיר? 🎵

משחק זיהוי שירים לכמה שחקנים, כל אחד מהטלפון (או מהמחשב) שלו. בעברית, מימין לשמאל, עם מצב לילה.

- **האפליקציה:** https://ma-hashir.pages.dev (אפשר להתקין במסך הבית)
- **השרת:** https://ma-hashir-api.guygitter.workers.dev

## איך משחקים
1. בפעם הראשונה: שם ותמונה. "משחק חדש" פותח משחק עם קוד בן 5 תווים, ושולחים לחברים קישור (`?g=<קוד>`).
2. מי שפתח את המשחק בוחר:
   - **כל אחד לעצמו** או **קבוצה נגד קבוצה** (🔵 הכחולים / 🔴 האדומים – כל אחד עובר לקבוצה שלו, או "ערבוב").
     ניקוד קבוצה = **ממוצע** של השחקנים בה, כדי שקבוצה גדולה לא תנצח רק כי יש בה יותר אנשים.
   - **ישראליים / לועזיים / גם וגם**.
   - **שנים:** 60, 70, 80, 90, 2000, 2010, 2020 או כל השנים. כשאין מספיק שירים בעשור (למשל ישראליים משנות ה-60) – משלימים מהעשורים הקרובים.
   - **10 או 20 שאלות**.
3. בכל שאלה: ספירה לאחור, ואז כולם שומעים **5 שניות** מהשיר באותו רגע, ויש **30 שניות** לבחור מתוך 4 תשובות
   (3 התשובות הלא נכונות – שירים באותה שפה, עדיף מאותו עשור).
   - **⏩ הארכה ל-10 שניות** – שומעים יותר, אבל תשובה נכונה שווה **5** במקום **10**.
   - **✂️ 50:50** – כל 30 נקודות שצוברים = 50:50 אחד, שמוחק שתי תשובות לא נכונות.
   - "🔁 לשמוע שוב" – אפשר בלי הגבלה (באותו אורך).
4. כשכולם ענו (או שהזמן נגמר) – רואים את התשובה הנכונה, מי צדק, וממשיכים לשמוע את השיר. אחרי 7 שניות – השאלה הבאה.
5. בסוף: דירוג, ו"עוד משחק" (שירים שלא היו עדיין בחדר הזה).

## השירים (`api/songs.js`, `api/library.js`)
- הרשימה ב-`api/songs.js`: לכל שפה ועשור – "שם השיר|הזמר/ת". להוספת שיר – שורה חדשה.
- את הקטע להשמעה (30 שניות, "תצוגה מקדימה" רשמית) השרת מוצא לבד: קודם ב-**iTunes** (ישראליים בחנות הישראלית), ואם לא נמצא –
  ב-**Deezer**. בלי מפתחות ובלי עלות. הקטע הוא מה שהחנות בחרה – לא תמיד ההתחלה המדויקת של השיר.
- שיר שלא נמצא (או נמצאה רק גרסת קריוקי/כיסוי) – פשוט לא נכנס למשחק. אם אין לפחות 5 שירים – הודעה "נסו שוב".
- Durable Object אחד (`Library`) זוכר מה נמצא – חודש (מה שלא נמצא – 3 ימים), כדי לא לחפש בכל משחק.
- הקטע עובר דרך השרת (`GET /audio`), נטען מראש בזמן הספירה לאחור ומתנגן בדיוק 5/10 שניות (Web Audio).
  באייפון מבקשים לנגן גם כשהטלפון על "שקט" (`navigator.audioSession`).

## איך זה בנוי
- `api/` – Cloudflare Worker + Durable Object `Room` לכל משחק (`api/room.js`), חוקי המשחק ב-`api/game.js`.
  אין סיסמה: לכל שחקן מזהה + סוד שנוצרים במכשיר. עד 16 שחקנים. משחק שלא נגעו בו 3 ימים נמחק.
- האפליקציה שואלת את השרת כל שנייה "מה חדש?"; המעבר בין השאלות לפי השעון של השרת – לכולם באותו רגע.
  התשובה הנכונה נשלחת רק אחרי שהשאלה נגמרה.
- `web/` – React + Vite + Tailwind. מסכים ב-`src/components`: פרופיל, בית, חדר המתנה (`Lobby`), שאלה (`Question`), סוף (`Over`).
  ההגדרות (שנים, שפה...) כפולות ב-`api/game.js` וב-`web/src/lib/game.js` – לשנות בשניהם.

## עלייה לאוויר
`.github/workflows/ma-hashir.yml` – אחרי מיזוג ל-main (בודק ובונה גם ב-PR). משתמש בסודות הקיימים
`CLOUDFLARE_API_TOKEN` ו-`CLOUDFLARE_ACCOUNT_ID`.

## בדיקה
- `cd ma_hashir/api && npm test` · `cd ma_hashir/web && npm test && npm run build`
- בדפדפן: לבנות עם `VITE_API_URL=http://localhost:8787` ולהריץ את ה-Worker מקומית (`npx wrangler dev`),
  או שרת מדומה שמחזיר צליל במקום שיר (ה-chromium כאן בלי AAC, ובלי גישה ל-iTunes).
