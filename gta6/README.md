# GTA 6 – סרטונים וקודים

מקום אחד לסרטונים על GTA 6: מדביקים קישור (פייסבוק, אינסטגרם, טיקטוק, יוטיוב), ו-Claude כותב לכל סרטון
**כותרת שאומרת מה יש בו**, תקציר קצר, ו**רשימת קודים** אם הסרטון נותן קודים. הסרטונים מסודרים לקטגוריות לפי נושא.

כתובת: **https://gta6-videos-97q.pages.dev** (Cloudflare Pages, `.github/workflows/gta6.yml`).
(השם gta6-videos.pages.dev תפוס – Cloudflare הוסיף לשם שלנו את הסיומת 97q.)

## מה יש

- **הוספה** – הדבקת קישור (או כמה בבת אחת). טקסט שליד הקישור נשמר כהערה. אותו קישור פעמיים – לא נשמר שוב.
- **שיתוף מהטלפון** – אחרי "הוספה למסך הבית" (אנדרואיד) האפליקציה מופיעה בתפריט "שיתוף".
- **הקריאה** רצה ברקע בשרת (אפשר לסגור את האפליקציה): כותרת, תקציר, קודים (`{ code, effect, platform }`), קטגוריה ותגיות.
  - פייסבוק / אינסטגרם / טיקטוק: השרת קורא את הכיתוב של הפוסט כמו "תצוגה מקדימה של קישור" (`userAgent` ב-`api/source.js`).
    לא נפתח – הסוכן מנסה לקרוא בעצמו (web_fetch).
  - יוטיוב: כותרת, תיאור וכתוביות (מה שנאמר בסרטון) – שם נאמרים הרבה קודים.
  - **צפייה בסרטון עצמו – Gemini של Google** (`api/google.js`): רואה את המסך ושומע את הקול (Claude לא יכול), ומה שהוא ראה ושמע
    (`watched`: דיבור, טקסט על המסך, קודים) עובר ל-Claude, שקורא שוב וכותב כותרת וקודים. Claude לא ממציא קודים.
    - יוטיוב – Gemini צופה ישירות מהקישור.
    - פייסבוק / אינסטגרם / טיקטוק – הורדה אוטומטית: השרת שולח אות ל-`.github/workflows/gta6-fetch.yml` (yt-dlp, `gta6/fetcher/fetch.py`),
      שמוריד ומעלה לשרת. בלוג הציבורי לא מודפס הקישור. נכשל / לא חזר תוך 15 דקות → "העלאת הסרטון מהטלפון".
    - העלאה מהטלפון: `/video/upload` (עד 95MB), עוברת בזרם ישר ל-Files API של Gemini; הקובץ נמחק אצל Google אחרי הצפייה.
    - המודל נבחר לבד (ה-Flash החדש ביותר, `pickWatchModel`); אפשר לקבוע `WATCH_MODEL`. תקרה: `DAILY_VIDEOS` צפיות ביום (`wrangler.toml`).
- **כל הקודים** – אריח במסך הראשי (`#/codes`): כל הקודים מכל הסרטונים, עם חיפוש וכפתור העתקה, ומעבר לסרטון שממנו הגיעו.
- **עריכה ידנית** – כותרת, קודים (נשמרים גם אחרי "לקרוא שוב" – `codesEdited`), קטגוריה, הערה, מחיקה. שינוי שם / איחוד קטגוריה.
- **חיפוש** בכותרות, תקצירים, קודים, תגיות והערות. **מצב לילה**, טלפון ומחשב.

## איך זה בנוי

- `web/` – React + Vite + Tailwind. הצבעים ב-`src/index.css` (שקיעה ורודה-כתומה; משתנים שמתחלפים במצב לילה).
  העזרים ב-`src/lib/videos.js` (סרטון ישן בלי `codes` עובר דרך `codesOf`).
- `api/` – Cloudflare Worker "gta6-videos-api" עם Durable Object אחד (`library.js`). ההוספה שומרת מיד, ו-alarm קורא ברקע.
  קריאת הדף: `source.js`; הסוכן: `ai.js` (`claude-opus-5-5`, effort נמוך).
- **בלי סיסמה**: כל מי שיודע את הכתובת יכול לראות, להוסיף ולמחוק. כדי שזר לא יריץ עלויות של Claude – עד 100 הוספות ביום
  (`MAX_PER_DAY` ב-`api/library.js`).
- נבנה על בסיס "מאגר AI" (`ai_maagar/`), אבל נפרד לגמרי (שרת ונתונים משלו).

## הגדרה

הסודות `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `POINTS_GITHUB_TOKEN` (נכנס לשרת כ-`GITHUB_TOKEN`: מפעיל את ההורדה, וההורדה מזדהה איתו),
`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` כבר קיימים ב-GitHub.

## בדיקה

- `cd gta6/api && npm test`
- `cd gta6/web && npm test && npm run build` (מול שרת מקומי: `VITE_API_URL=...`)
