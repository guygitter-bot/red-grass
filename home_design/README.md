# מעצב הבית

מצלמים קיר או חדר בבית, כותבים מה רוצים לשנות (או מבקשים רעיונות מהמעצב), ומקבלים תמונה של אותו חדר אחרי השינוי –
עם השוואת לפני / אחרי. אפליקציה אישית בעברית (RTL), לטלפון ולמחשב, עם מצב לילה לפי המכשיר.

- האפליקציה: https://meatzev-habayit.pages.dev (`web/`, React + Vite + Tailwind)
- השרת: `meatzev-habayit-api` (`api/`, Cloudflare Worker בלי שמירת נתונים)
- עלייה לאוויר: אוטומטית אחרי מיזוג ל-main (`.github/workflows/home-design.yml`)

## איך זה עובד

1. **צילום** – התמונה מוקטנת בטלפון (עד 1600 פיקסלים) ונשמרת **רק במכשיר** (IndexedDB). השרת לא שומר כלום.
2. **הצעות מהמעצב** (`POST /ideas`) – Claude (`claude-opus-5-5`) מסתכל על הצילום ומחזיר תיאור קצר של החדר ו-4 כיווני עיצוב:
   כותרת והסבר בעברית + הוראה מדויקת באנגלית למחולל התמונות. אפשר להוסיף "מה חשוב לך".
3. **הדמיה** (`POST /render`) – מחולל התמונות של Google (Gemini API) מקבל את התמונה ואת השינוי ומחזיר את אותו חדר אחרי
   השינוי. בקשה חופשית עובדת על התמונה שמוצגת (אפשר להמשיך מהדמיה להדמיה); הצעה של המעצב תמיד מתחילה מהצילום המקורי.
4. **לפני / אחרי** – גוררים קו על התמונה. כל הדמיה נשמרת כגרסה, ואפשר לשתף, להוריד או למחוק.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `api/worker.js` | הכתובות, בדיקת הקלט ו-CORS (רק מכתובת האפליקציה) |
| `api/designer.js` | המעצב: ההנחיות ל-Claude וקריאת ההצעות |
| `api/render.js` | מחולל התמונות: ההוראה, הקריאה ל-Google, ומציאת מודל אחר אם השם שבהגדרות כבר לא קיים |
| `web/src/components/` | `Home` (רשימת החדרים), `Project` (חדר אחד), `Compare` (לפני / אחרי) |
| `web/src/lib/` | `api` (שרת), `image` (הקטנה, שיתוף), `store` (שמירה במכשיר), `design` (קיצורים: צבעים, סגנונות) |

## סודות (ב-GitHub, לא בקוד)

- `ANTHROPIC_API_KEY` – כבר קיים במאגר.
- `GEMINI_API_KEY` – מפתח מ-Google AI Studio (https://aistudio.google.com/apikey). יצירת תמונות דורשת חיוב פעיל בחשבון.
  בלי המפתח האפליקציה עולה, אבל מודיעה שמחולל התמונות עוד לא מחובר. אחרי שמוסיפים אותו – להריץ שוב את `home-design.yml`.

שם המודל של Google ב-`api/wrangler.toml` (`IMAGE_MODEL`). אם Google מחליפה שם, השרת מוצא לבד מודל תמונות ברשימה שלה.

## בלי סיסמה ובלי תקרת הוצאה

המשתמש ביקש (אפליקציה אישית). ההגנה היחידה: הדפדפן מורשה לפנות לשרת רק מכתובת האפליקציה. מי שיודע את כתובת השרת
יכול לפנות אליו ישירות – אם זה יהפוך לבעיה, להוסיף סיסמה (כמו ב-`suno_course/api`).

## בדיקה

```
cd home_design/api && npm test
cd home_design/web && npm test && npm run build
```

שינוי במסך: לבדוק בדפדפן עם Playwright ושרת מדומה (לבנות עם `VITE_API_URL=http://localhost:9999` ו-`page.route`).

## רעיונות שלא בוצעו

- לסמן באצבע על התמונה איזה קיר / אזור לשנות.
- רשימת קניות וחומרים להדמיה שנבחרה (צבע, כמות, הערכת עלות).
- כמה הדמיות במקביל לאותה בקשה, לבחירה.
- סנכרון החדרים בין הטלפון למחשב (היום כל מכשיר שומר לעצמו).
