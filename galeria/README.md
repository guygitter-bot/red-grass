# גלריה מסודרת (`galeria/`)

אפליקציית אנדרואיד שעושה סדר בגלריה: ממיינת את התמונות לנושאים ולמקורות, מוצאת כפולות ודומות, מטושטשות,
חשוכות וצילומי מסך ישנים – ועוזרת למחוק כמה שיותר תמונות מיותרות. **הכול בתוך הטלפון** – שום תמונה לא יוצאת ממנו.

- אתר (גלריה לדוגמה + הורדת האפליקציה): https://galeria-app.pages.dev · האפליקציה: https://galeria-app.pages.dev/galeria.apk
- עלייה: `.github/workflows/galeria.yml` אחרי מיזוג ל-main (בודק, בונה APK, מעלה לאתר). ב-PR – בודק ובונה בלבד.

## אפיון

### מה האפליקציה עושה
1. **סריקה** – קוראת את רשימת התמונות (MediaStore), ולכל תמונה מחשבת בטלפון:
   טביעת אצבע (dHash, 64 סיביות), חדות (שונות לפלסיאן), בהירות, ותוויות תוכן (ML Kit Image Labeling – מודל שבתוך האפליקציה, בלי אינטרנט).
   התוצאות נשמרות בטלפון (`localStorage`), כך שבפעם הבאה נבדקות רק תמונות חדשות.
2. **הצעות ניקוי** (מסך הבית, עם כמה מקום יתפנה):
   - 👯 כפולות – כמעט זהות (מרחק ≤ 3), גם בזמנים שונים. משאירים אחת.
   - 🎞️ דומות – מרחק ≤ 11 וצולמו בהפרש של עד שעה (רצף צילומים). משאירים את הטובה (חדה, גדולה, לא חשוכה, מועדפת).
   - 🌫️ מטושטשות – חדות נמוכה מאוד ביחס לחציון של הגלריה. 🌑 חשוכות – בהירות < 28.
   - 📱 צילומי מסך מלפני יותר מחודש · 💬 תמונות מוואטסאפ מלפני 3 חודשים · 🐘 הכי כבדות.
   - מועדפות (❤️ בגלריה) לא מוצעות למחיקה. מה שהמשתמש השאיר – לא מוצע שוב.
3. **קטגוריות**: לפי נושא (אנשים, אוכל, בעלי חיים, טבע, מסמכים, עיר, רכבים, אירועים, שונות) ולפי מקור
   (מצלמה, וואטסאפ, צילומי מסך, הורדות, רשתות חברתיות, אחר). בכל קטגוריה אפשר לסמן ולמחוק.
4. **מחיקה בטוחה**: רק מה שמסומן. אנדרואיד מציג חלון אישור משלו, והתמונות עוברות **לפח של הגלריה** (שחזור 30 יום).
   עובד מאנדרואיד 11 ומעלה (`MediaStore.createTrashRequest`).

### מבנה
- `web/src/lib/similar.js` – קיבוץ כפולות/דומות ובחירת הטובה (פונקציות טהורות + בדיקות).
- `web/src/lib/cleanup.js` – הצעות הניקוי וחישוב המקום שיתפנה. `categories.js` – מקור ונושא (מילים של ML Kit → נושא).
- `web/src/lib/source.js` – גישה לתוסף `Gallery` בטלפון; בדפדפן – `demo.js` (גלריה מצוירת לבדיקות).
- `web/src/lib/store.js` – מטמון הניתוח והתמונות שסומנו "להשאיר".
- `mobile/android/app/src/main/java/app/galeria/GalleryPlugin.java` – הקוד של אנדרואיד:
  `access` (הרשאה), `list`, `analyze({ids})`, `thumb({id,size})`, `open({id})`, `trash({ids})`.
- הרשאות: `READ_MEDIA_IMAGES` (אנדרואיד 13+), `READ_EXTERNAL_STORAGE` (ישנים). אין הרשאת אינטרנט בשימוש לתמונות.
- חתימה: `debug.keystore` קבוע במאגר (לא סודי), כדי שגרסה חדשה תותקן מעל הקודמת.

### בדיקה
- `cd galeria/web && npm test && npm run build`
- בדפדפן (Playwright) – גלריה לדוגמה. קוד האנדרואיד נבנה ב-GitHub Actions (אין כאן Android SDK).

### התקנה בטלפון
להוריד את `galeria.apk` מהאתר בכרום בטלפון → לפתוח → לאשר "התקנה ממקור לא ידוע" לכרום (פעם אחת) → להתקין.
גרסה חדשה – מורידים ומתקינים שוב (הנתונים נשמרים).
