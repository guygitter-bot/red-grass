# יומן סוכר

יומן משותף (טלפון ומחשב, מותקן מהדפדפן: "הוספה למסך הבית") למעקב אחרי ארוחות, מדידות סוכר ואינסולין –
כדי ללמוד, ארוחה אחרי ארוחה, כמה אינסולין מתאים לכל ארוחה. כמה אנשים (הורים, סבים, מטפלים) נכנסים עם אותה סיסמה
ורואים ועורכים את אותו יומן.

כתובת: **https://yoman-sukar.pages.dev** · שרת: Worker `yoman-sukar-api` (סוד `ANTHROPIC_API_KEY` לשיחה עם ה-AI) ·
עלייה: `.github/workflows/yoman-sukar.yml` אחרי מיזוג ל-main.

## מה יש

- **היום** (`DayView.jsx`) – גרף הסוכר של היום (24 שעות, פס ירוק לטווח היעד, קו לכל ארוחה עם מספר היחידות), כרטיס לכל
  ארוחה: שעה, מה אכל, כמה מנות, סוכר לפני, אינסולין, ומדידות אחרי בצבע (אדום נמוך / ירוק בטווח / כתום גבוה).
  "מדידה אחרי" – הוספה מהירה (שעה + ערך). "מדידה בלי ארוחה" – בוקר, לילה, ספורט. חצים ליום הקודם/הבא.
  **תזכורת**: עברו שעתיים מארוחה עם אינסולין ואין מדידה – מופיע פס "הגיע הזמן למדוד".
- **ארוחה** (`MealEditor.jsx`) – שם (או מהתפריט), שעה, סוג (בוקר / עשר / צהריים / ארבע / ערב / לילה), מה אכל, מנות
  (½, 1, 1½, 2, 3 או מספר אחר), פחמימה (לא חובה), סוכר לפני, אינסולין, מדידות אחרי (כמה שרוצים, עם "+2:00" מהארוחה),
  סימונים (ספורט, חולה, לחץ, שומני, אינסולין באיחור, טיפול בהיפו, אירוע) והערה. **"בפעמים הקודמות"** – טבלה של
  הפעמים האחרונות של אותה ארוחה: מנות, לפני, אינסולין, שעתיים אחרי. אם בהגדרות יש יחס פחמימות ופקטור תיקון מהצוות –
  מוצג חישוב לפיהם (מסומן "חישוב בלבד").
- **תפריט קבוע** (`MenuView.jsx`) – ארוחות שחוזרות (שם, שעה, מה אוכלים, מנה, פחמימה, אינסולין רגיל, באילו ימים).
  במסך היום: "להוסיף את כל התפריט הקבוע" בלחיצה, או ארוחה אחת. לכל ארוחה קבועה – הדפוס שלה: אינסולין ממוצע (ולמנה),
  לפני, שעתיים אחרי, כמה בטווח, נפילות, ו"מה שעבד" (מנות + יחידות שהסתיימו בטווח בלי נפילה). "להוריד מהתפריט" לא מוחק.
- **מעקב** (`StatsView.jsx`) – שבוע / שבועיים / חודש / 3 חודשים: אחוז בטווח, ממוצע וסטיית תקן, נמוכים, גבוהים,
  הערכת GMI (המוגלובין מסוכרר לפי הממוצע – הערכה בלבד), ממוצע לפי שעות היום, טבלה לכל ארוחה, וממוצע לכל יום (לחיצה פותחת).
- **שאלות ל-AI** (`ChatView.jsx`) – שיחה כמו בוואטסאפ, **משותפת** לכל מי שנכנס (כל הודעה היא רשומה `chat` עם שם השואל).
  בכל שאלה נשלח סיכום מלא ועדכני של היומן (`aiContext` ב-`diary.js`: הגדרות, סטטיסטיקה, ממוצע לפי שעות, התפריט,
  דפוס לכל ארוחה ב-60 יום ופירוט מלא של 21 הימים האחרונים) + 12 ההודעות האחרונות. השרת (`api/ai.js`) – Claude
  (`claude-opus-5-5`, effort high), עד 60 שאלות ביום. ההנחיות: לנתח את הנתונים לעומק, לצטט תאריכים וערכים, לא להמציא,
  **לא לתת מינון כהוראה** (רק מה שהנתונים מראים + "לבדוק עם הצוות"), ואזהרה ברורה על נמוכים ומצבי חירום.
- **הגדרות** – "מי אני" (נשמר במכשיר, נרשם ליד ארוחות והודעות), שיתוף קישור, שם, טווח יעד (ברירת מחדל 70-180),
  יחס פחמימות / פקטור תיקון / יעד (לא חובה), "דברים שחשוב שה-AI יידע", מצב לילה, ייצוא לאקסל (CSV לרופא/ה),
  גיבוי ושחזור לקובץ, החלפת סיסמה (מנתקת את שאר המכשירים), יציאה.

## איפה הנתונים

- כל מכשיר שומר עותק (localStorage) – האפליקציה עובדת גם בלי אינטרנט.
- בשרת (`api/diary.js`, Durable Object אחד): כל רשומה עם `updatedAt`; העריכה המאוחרת גוברת; מחיקה = `deleted: true`.
  כל שינוי מקבל `rev`, והמכשיר מבקש "מה השתנה מאז" (`/sync`). סנכרון: בפתיחה, כשחוזרים לאפליקציה, כשהרשת חוזרת,
  פעם בדקה ושנייה וחצי אחרי שינוי (`web/src/lib/store.js`) – כך שכולם רואים את אותו מצב.
- **סיסמה אחת**, שנקבעת בכניסה הראשונה בכלל (`/setup`). כל מכשיר נכנס פעם אחת ונשאר מחובר (שנה, מתחדש בשימוש).
  10 טעויות ברצף – נעילה לרבע שעה.

## מבנה הרשומות (`web/src/lib/diary.js`)

- `settings` (מזהה `settings`): `person`, `low`, `high`, `icr`, `cf`, `target`, `note`.
- `template`: `name`, `slot`, `time`, `food`, `portion`, `carbs`, `dose`, `days` (0=ראשון; ריק = כל יום), `archived`.
- `meal`: `date`, `time`, `templateId`, `name`, `slot`, `food`, `portion`, `carbs`, `before`, `insulin`,
  `readings: [{time, value}]`, `tags`, `note`, `by`. מדידה אחרי חצות של ארוחת ערב נחשבת ליום הבא.
- `reading`: `date`, `time`, `value`, `note`, `by`. `chat`: `role`, `text`, `at`, `by`.
- שדה חדש – חייב ברירת מחדל ב-`safeMeal` / `safeTemplate` / `safeSettings` (רשומות ישנות מסתנכרנות בלי אותו שדה).

- `cd sugar/api && npm test` · `cd sugar/web && npm test && npm run build`
