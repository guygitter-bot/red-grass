# ספר אישי

אפליקציה בעברית (RTL) שיוצרת **ספר דיגיטלי אישי במתנה**: מספרים על מישהו אהוב, והסופר (Claude) כותב עליו ספר שלם –
שם, הקדשה, פרקים – והמאייר (Google) מצייר כריכה ואיור לכל פרק. קוראים את הספר על המסך ושולחים אותו בקישור.
בלי הדפסה, בלי תשלום ובלי סיסמה.

- האפליקציה: https://sefer-ishi.pages.dev
- השרת: https://sefer-ishi-api.guygitter.workers.dev

## איך זה עובד (למשתמש)

1. **שאלון** (4 צעדים): אירוע (יום הולדת, יום נישואין, חתונה, מחווה רומנטית, צחוקים, סיפור לילד/ה, סתם מתנה, אחר) ←
   על מי הספר (שם, לשון זכר/נקבה, מי הוא בשבילכם, גיל, ממי) ← כמה שאלות פתוחות לפי האירוע + טון ←
   תמונות (עד 6), סגנון איור, אורך (6 / 10 / 14 פרקים) והקדשה.
2. **מתווה**: הסופר מחזיר שם לספר, הקדשה ורשימת פרקים, והכריכה מצוירת. אפשר לשנות הכול (שם, הקדשה, פרקים – לערוך, למחוק, להוסיף).
3. **כתיבה**: אחרי אישור, הספר נכתב פרק אחרי פרק (ואיור אחרי כל פרק). אפשר לקרוא תוך כדי. אם סוגרים – ממשיך מאותה נקודה.
4. **קריאה**: דף אחרי דף – כריכה, הקדשה, תוכן העניינים, פרקים, אלבום תמונות, סוף. חיצים, מקלדת או החלקה; גודל כתב.
5. **עריכה**: לכל פרק – לתקן את הטקסט ביד, לבקש מהסופר לכתוב מחדש (עם הערה), או איור חדש.
6. **שיתוף**: "ליצור קישור לספר" מעלה עותק לקריאה. מי שמקבל את הקישור קורא בלי להתקין כלום. אפשר לעדכן או לבטל את הקישור.

## מבנה

- `web/` – React + Vite + Tailwind → Cloudflare Pages `sefer-ishi`.
  - `src/lib/brief.js` – האירועים, השאלות, הטונים, הסגנונות והאורכים.
  - `src/lib/book.js` – מבנה הספר ומה נשאר לעשות בו (פונקציות טהורות + בדיקות).
  - `src/lib/maker.js` – תהליך היצירה ברקע: כריכה, ואז פרק ואיור לסירוגין. כל צעד נשמר מיד.
  - `src/lib/store.js` – השמירה במכשיר (IndexedDB): ספרים ותמונות.
  - `src/components/` – `Home` (הספרים שלי), `Wizard` (השאלון), `Book` (מתווה / כתיבה / שיתוף / עריכת פרק), `Reader` (קריאה).
- `api/` – Cloudflare Worker `sefer-ishi-api` + Durable Object `Shelf` אחד.
  - `worker.js` – הכתובות (רשימה בראש הקובץ). `brief.js` – ניקוי הבריף. `writer.js` – ההוראות לסופר (מתווה ופרק).
  - `illustrate.js` – המאייר (Gemini). `ai.js` – הפנייה ל-Claude. `shelf.js` – ספרים ששותפו + מונה יומי.

## איפה הנתונים

- **הספרים נשמרים במכשיר של מי שיצר אותם** (IndexedDB). מי שמוחק את נתוני הדפדפן – מאבד אותם.
- **בשרת נשמר רק ספר ששותף בקישור**: הטקסט והתמונות שבספר. מה שנכתב בשאלון לא עולה לשרת. ביטול הקישור מוחק את העותק.
- תמונה של גיבור הספר נשלחת למאייר (Google) רק אם סימנו "לאייר את הדמות לפי התמונה".

## הגנות

- אין סיסמה. השרת עונה רק לדפדפן מכתובת האפליקציה (`ALLOWED_ORIGIN_RE`).
- **תקרה יומית** לכל המשתמשים יחד (`api/wrangler.toml`): `DAILY_TEXT` (קריאות כתיבה), `DAILY_IMAGES` (איורים), `DAILY_SHARES` (קישורים).
  ספר רגיל = 11 קריאות כתיבה ו-11 איורים.
- הסופר מקבל הוראה לא להמציא עובדות על האדם, ולשמור על לשון זכר/נקבה.

## סודות (ב-GitHub, לא בקוד)

`ANTHROPIC_API_KEY` (חובה), `GEMINI_API_KEY` (בלי המפתח – ספרים בלי איורים), `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.
שם מודל האיורים: `IMAGE_MODEL` ב-`api/wrangler.toml`.

## בדיקה

```
cd sefer/api && npm test
cd sefer/web && npm test && npm run build
```

שינוי במסך: לבדוק בדפדפן (Playwright) מול שרת מקומי – לבנות עם `VITE_API_URL=http://localhost:<port>`.
