# מילים באנגלית – תרגול לילדים

35 המילים מדף אוצר המילים של בית הספר (`web/public/words.js`).

- מופיעה מילה באנגלית → הילד לוחץ על 🎤 ואומר אותה (זיהוי דיבור של הדפדפן, `en-US`).
  🔊 משמיע את המילה. אחרי 3 ניסיונות אפשר להמשיך בכל זאת (הזיהוי לא מושלם).
- אחרי קריאה נכונה – 4 תרגומים מתוך הרשימה, בוחרים את הנכון. תשובה נכונה בפעם הראשונה = כוכב והמילה מסומנת "למדתי".
- סיבוב = כל המילים בסדר אקראי. צריך 80% (תשובה נכונה בניסיון הראשון) – אחרת מתחילים שוב בסדר חדש.
- אחרי 80% במילים נפתח שלב 2: משפטים קצרים מהמילים (`web/public/sentences.js`), 4 תרגומים (השגויים דומים למשפט), אותו סף 80%.
- ההתקדמות (כוכבים, שלבים) נשמרת בטלפון. בכניסה הראשונה הילד כותב את השם שלו; כל סיבוב שהסתיים נשלח לשרת
  (`web/public/report.js`, עם תור כשאין רשת). מילים שלא נלמדו מופיעות קודם.
- **ניהול להורים** (`admin/public`, Pages `milim-admin`): לכל ילד – עבר 80%? אחרי כמה ניסיונות, הכי טוב/ממוצע/אחרון,
  המילים שהכי קשות לו, וכל הסיבובים. הכניסה הראשונה קובעת סיסמה (נשמרת מוצפנת בשרת; 10 טעויות = נעילה לרבע שעה).
- **שרת** (`api/`, Worker `milim-api`, Durable Object `Tracker` אחד): `/round` מהאפליקציה, `/admin/*` עם סיסמה.
  כתובת השרת ב-`config.js` – זהה ב-`web` וב-`admin` (ה-workflow בודק).
- בלי בנייה: `web/public` עולה כמו שהוא → https://milim-beanglit.pages.dev (`english-words.yml` אחרי מיזוג ל-main).
- בדיקה: `cd english_words/api && npm test` · `cd english_words/web && npm test` · `cd english_words/admin && npm test`. מילים שהמיקרופון שומע לא נכון – להוסיף ל-`alt` של המילה.
