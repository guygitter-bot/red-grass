# זימון חלומות (`dreams/`)

אפליקציה בעברית (RTL, PWA) לזימון חלומות: לבחור על מה לחלום, לעשות טקס שינה קצר, ולרשום את החלום ברגע ההתעוררות.
בלי שרת: **כל הנתונים נשמרים רק במכשיר** (localStorage `zc_data`). יש גיבוי ושחזור לקובץ בהגדרות.

- `web` (React + Vite + Tailwind) → https://zimun-chalomot.pages.dev. עלייה: `.github/workflows/dreams.yml` אחרי מיזוג ל-main.
- בדיקה: `cd dreams/web && npm test && npm run build`.

## המסכים (`web/src/screens/`)
| מסך | כתובת | מה עושים בו |
|---|---|---|
| הלילה | `#/` | בערב: הכוונה ללילה. בבוקר: לרשום חלום. תנומת אדיסון, מספרים, אחרונים ביומן |
| כוונה | `#/intend` | סוג (`lib/kinds.js`), שאלה, משפט כוונה, תמונה אחת |
| טקס השינה | `#/ritual` | 6 שלבים: שאלה, 6 נשימות, תמונה, משפט ×3, הוראות להתעוררות, מסך לילה עמום |
| תנומת אדיסון | `#/nap` | מחזיקים את הירח; שחרור אחרי 20 שניות או יותר = צלצול, ורושמים מה עלה (כמה סבבים) |
| בוקר | `#/morning` | רגע של שקט, ואז טופס (`components/DreamForm.jsx`) או "לא נזכרתי" |
| יומן / חלום | `#/journal[/<חיפוש>]`, `#/entry/<id>` | חיפוש, קריאה, עריכה, מחיקה |
| תובנות | `#/insights` | אחוז זכירה, רצף, הצלחת זימון לפי סוג, סמלים חוזרים, תחושות |
| ללמוד | `#/learn` | המחקר עם מקורות, מסורת, שיטות, בטיחות |
| הגדרות | `#/settings` | מצב לילה, צלצול, קול, סבבים, גיבוי/שחזור, מחיקה |

## הלוגיקה (`web/src/lib/`, פונקציות טהורות + בדיקות)
- `night.js` – **מפתח לילה**: מ-15:00 עד 15:00 למחרת זה אותו לילה (כוונה ב-23:30 וחלום ב-07:00 → אותו לילה).
- `store.js` – `safeData` / `safeEntry` / `safeIntention` / `safeSettings`: שדה חדש חייב ברירת מחדל שם. `mergeImport` לשחזור (מאחד, לא מוחק).
- `lenses.js` – ארבע עדשות לפירוש חלום (Human Design, יונג, מסורת ישראל, שיטות טיפוליות): `LENSES`, `HD_TYPES` / `HD_AUTHORITIES`, ו-`lensQuestions(lens, entry, settings, intention)` (שאלות מותאמות; בלי AI ובלי רשת). התשובות ב-`entry.lensNotes`, הסוג והתוקף ב-`settings.hd`. מסך החלום: `components/LensSection.jsx`; מקורות ב"ללמוד".
- `stats.js` – זכירה, רצף, הצלחת זימון, תגיות, חיפוש.
- `night-tools.js` – מסך דולק (Wake Lock, מתחדש כשחוזרים לאפליקציה), צלצול ב-WebAudio, הקראה (רק אם יש קול עברי במכשיר), רטט.

## על מה זה מבוסס
- Barrett 1993 (Dreaming 3:2): בערך מחצית חלמו על הבעיה בתוך שבוע; כ-70% מהם הרגישו שהחלום הכיל פתרון. → טקס השינה.
- Lacaux et al. 2021 (Science Advances): 15 שניות לפחות בשלב N1 → 83% גילו את הכלל, לעומת 30%. → תנומת אדיסון.
- Haar Horowitz et al. (MIT, Dormio 2020; 2023): זימון ממוקד בהירדמות, 49 משתתפים, יצירתיות גבוהה ב-43%. → תזכורת בקול והשאלה "מה עבר לך בראש".
- Aspy et al. 2017/2020: MILD + WBTB הכי יעילים לחלום צלול. → סוג הכוונה "חלום צלול".
- זהירות: שיטות שמעירות בלילה מקטעות שינה; לא ייעוץ רפואי (מסך "ללמוד").
