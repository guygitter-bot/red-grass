# טוטו חכם – שלב 1

כל יום חמישי ב-08:45 (שעון קיץ) הרצה אוטומטית ב-GitHub Actions:

1. **איתור הטופס:** סוכן Claude מחפש ברשת את טופס טוטו 16 הפתוח (16 המשחקים, מספר המחזור ומועד הסגירה).
2. **מחקר:** סוכן נפרד לכל משחק, 4 במקביל. הסוכן אוסף יחסים, ראש בראש ב-10 השנים האחרונות, פצועים ומורחקים, עומס משחקים, שחקני נבחרת, ביתיות ועונשי קהל, כושר ומוטיבציה, וכותב סיכום בעברית עם מקורות.
   - **הכול לפי המידע של יום חמישי:** הטופס נשלח ביום חמישי, וההרכבים מתפרסמים רק כשעה לפני כל משחק.
   - **שחקנים בספק** מסומנים `doubtful` ונספרים כחצי היעדרות.
   - **עייפות:** נספרים גם משחקים שעוד יתקיימו לפני המשחק בטופס, למשל ליגה אירופית בחמישי בערב.
   - **עונות קודמות:** מארכיוני הטבלאות והתוצאות של ההתאחדות, ספורט 5, ONE ואחרים: מיקום ב-3 העונות האחרונות, נקודות למשחק בבית ובחוץ, ושיעור התיקו בליגה.
   - **שעת המשחק ומזג האוויר:** התחזית לשעת הפתיחה נשלפת מ-Open-Meteo (חינמי, בלי מפתח) לפי מיקום האיצטדיון. חום, גשם ורוח מעלים את הסיכוי לתיקו.
   - **רוטציה:** הסוכן מעריך את הסיכוי שהמאמן ינוח שחקנים לקראת משחק חשוב.
3. **חיזוי:** `model.py` הופך את הנתונים להסתברויות 1/X/2 בנוסחה קבועה, בלי ניחושים של הסוכן.
4. **טופס:** `optimizer.py` בוחר כפולים ומשולשים עד 120 ₪ (40 טורים במחיר 3 ₪ לטור) כך שהסיכוי ל-16 יהיה מקסימלי.
5. **מועד סגירה:** שעת הפתיחה של המשחק הראשון בטופס פחות 6 דקות. הוא מופיע בהודעה ובאתר, ואם הטופס כבר נסגר לא נשלחות הודעות.
6. **תוצאה:** הנתונים נשמרים ב-`data/`, האתר מתעדכן ב-GitHub Pages, ונשלחות הודעות בוואטסאפ ובמייל.

## הגדרה חד-פעמית

### 1. סודות
ב-GitHub: **Settings ← Secrets and variables ← Actions ← New repository secret**

| סוד | מאיפה |
|---|---|
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com): Settings ← API Keys ← Create Key. צריך להוסיף אמצעי תשלום וקרדיט ב-Billing |
| `CALLMEBOT_PHONE` | המספר שלך בפורמט בינלאומי, למשל `+972501234567` |
| `CALLMEBOT_APIKEY` | שומרים בטלפון את המספר של CallMeBot ושולחים לו בוואטסאפ את הודעת ההפעלה. המספר וההודעה מופיעים ב-[דף ההוראות](https://www.callmebot.com/blog/free-api-whatsapp-messages/). המפתח מגיע בתשובה |
| `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD` | כבר קיימים (מסקריפט החשבוניות) |

אופציונלי, ב-**Variables**: `TOTO_EMAIL_TO` (כתובת יעד אחרת למייל. ברירת המחדל היא `GMAIL_ADDRESS`).

### 2. GitHub Pages
**Settings ← Pages ← Build and deployment ← Source: GitHub Actions**

כתובת האתר: `https://guygitter-bot.github.io/red-grass/`

### 3. בדיקה ראשונה
**Actions ← Weekly Toto 16 ← Run workflow**:
- `demo` מסומן: בודק את הצינור ואת האתר בלי קריאות API.
- `dry_run` מסומן: ריצה אמיתית עם Claude, בלי לשלוח הודעות.
- בלי סימון: ריצה מלאה.

> ריצות מתוזמנות של GitHub Actions רצות רק מהענף הראשי (`main`). לכן הקוד צריך להיות ממוזג ל-`main` כדי שהריצה של יום חמישי תפעל.
