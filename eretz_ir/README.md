# ארץ עיר

משחק "ארץ עיר" לכמה שחקנים, כל אחד מהטלפון (או מהמחשב) שלו. בעברית, מימין לשמאל, עם מצב לילה.

- **האפליקציה:** https://eretz-ir.pages.dev (אפשר להתקין במסך הבית)
- **השרת:** https://eretz-ir-api.guygitter.workers.dev

## איך משחקים
1. בפעם הראשונה: שם ותמונה (התמונה מוקטנת ל-160 פיקסלים ונשמרת רק במשחקים שמצטרפים אליהם).
2. "משחק חדש" פותח משחק עם קוד בן 5 תווים. שולחים לחברים קישור (`?g=<קוד>`) – בוואטסאפ, שיתוף או העתקה.
3. כל אחד יכול ללחוץ "מתחילים!". יוצאת אות (לא חוזרת עד שכל האותיות היו, ומדלגים גם על 15 האותיות האחרונות
   שהיו במכשיר של מי שלחץ – גם ממשחקים קודמים), ספירה לאחור של 3 שניות,
   ולכולם אותו זמן (ברירת מחדל 2 דקות; אפשר דקה עד 8 דקות) למלא: ארץ, עיר, חי, צומח, דומם, ילד, ילדה, מקצוע, מאכל.
4. הסיבוב נגמר כשהזמן נגמר או כשכולם לחצו "סיימתי". אז רואים את התשובות של כולם.

## קהילות חברים והתראות (`api/club.js`, `web/src/components/Clubs.jsx`)
- קהילה = קבוצת חברים/משפחה עם קוד בן 6 תווים וקישור הזמנה (`?c=<קוד>`). עד 50 חברים. רשימת הקהילות שלי נשמרת במכשיר.
- "🎲 משחק חדש וקריאה לכולם" (במסך הקהילה), או "📣 לקרוא לחברים" (בחדר ההמתנה): כל מי שהפעיל התראות מקבל לטלפון
  "🎲 שגיא רוצה לשחק ארץ עיר! בואו להצטרף – קוד ABCDE", ולחיצה מכניסה ישר למשחק. לכל היותר קריאה אחת בדקה לקהילה.
- גם בלי התראות: בדף הבית ובמסך הקהילה מופיע "שגיא רוצה לשחק!" חצי שעה אחרי הקריאה.
- התראות: Web Push בלי ספריות (`api/push.js` – העתק של `seder/api/push.js`). מפתחות VAPID נוצרים פעם אחת באובייקט
  `~vapid` (אחד לכל הקהילות). באייפון – רק כשהאפליקציה מותקנת במסך הבית. ה-service worker (`web/public/sw.js`) מציג את ההתראה.
- קהילה שלא נגעו בה חצי שנה נמחקת.

## ניקוד (`api/game.js`)
- תשובה נכונה שרק אחד כתב – **10**. אותה תשובה אצל כמה שחקנים – **5** לכל אחד.
- "אותה תשובה": בלי ניקוד, מקפים, רווחים כפולים (`תל-אביב` = `תל אביב`).
- **תיקון כתיב** (`api/spell.js`, Claude Sonnet): בסוף כל סיבוב תשובות שמתחילות באות הנכונה עוברות תיקון כתיב
  ("ארייה" → "אריה"), כי משחקים גם ילדים קטנים. התיקון חייב להתחיל באותה אות, ורק מתקן כתיב – לא מחליף מילה ולא שופט.
  בתוצאות רואים "תוקן מ..." ותשובות מתוקנות נחשבות לאותה תשובה (5 נקודות). אם התיקון נכשל או לוקח יותר מחצי דקה –
  התוצאות מוצגות בלי תיקון.
- **בדיקת התשובות** (באותה פנייה ל-Claude): האם התשובה באמת מתאימה לקטגוריה ("היי" במקצוע – לא; "בורר" – כן).
  תשובה לא מתאימה – 0 ("לא מתאים ל..."), אלא אם יותר ממחצית השחקנים האחרים מאשרים אותה ב-👍.
- אות אחת לבד (גם האות הנכונה) – 0 ("רק אות אחת"), ולא נשלחת לבדיקה.
- תשובה שלא מתחילה באות – 0.
- **בונוס סיום ראשון: 10** – למי שלחץ ראשון "סיימתי" (לפני סוף הזמן) עם כל השדות מלאים, אם לפחות מחצית התשובות שלו נכונות.
  ברגע שמישהו מסיים ראשון מתנגן אצל כולם צלצול נעים (`web/src/lib/sound.js`, בלי קובץ שמע). תשובה "לא נכונה" (למשל "בננה" ב"חי") – השחקנים מסמנים 👎, והיא נפסלת
  כשיותר ממחצית השחקנים האחרים סימנו אותה (בשניים – הקול של השני מספיק).
- הניקוד הכולל מצטבר מסיבוב לסיבוב. ניקוד של סיבוב נקבע סופית כשמתחיל הסיבוב הבא.

## איך זה בנוי
- `api/` – Cloudflare Worker + Durable Object `Room` לכל משחק (לפי הקוד). אין סיסמה: לכל שחקן מזהה + סוד
  שנוצרים במכשיר שלו (`localStorage`). עד 12 שחקנים. משחק שלא נגעו בו 3 ימים נמחק.
- האפליקציה שואלת את השרת כל 1.5 שניות "מה חדש?" (עם מספר גרסה – אם לא השתנה כלום התשובה קצרה).
  התשובות נשמרות תוך כדי כתיבה, והשעון לפי השרת – לכולם נגמר הזמן באותו רגע. 4 שניות חסד לתשובות שבדרך.
- `web/` – React + Vite + Tailwind. מסכים ב-`src/components`: פרופיל, בית, חדר המתנה, משחק, תוצאות.

## עלייה לאוויר
`.github/workflows/eretz-ir.yml` – אחרי מיזוג ל-main (בודק ובונה גם ב-PR). משתמש בסודות הקיימים
`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` ו-`ANTHROPIC_API_KEY` (לתיקון הכתיב). אם Cloudflare נותן לאתר כתובת עם סיומת (למשל `eretz-ir-abc.pages.dev`),
השרת כבר מאשר אותה (`ALLOWED_ORIGINS` ב-`api/wrangler.toml`) – רק לעדכן את הכתובת כאן.

## בדיקה
- `cd eretz_ir/api && npm test` · `cd eretz_ir/web && npm test && npm run build`
- בדפדפן: לבנות עם `VITE_API_URL=http://localhost:8787` ולהריץ את ה-Worker מקומית (`npx wrangler dev`).
